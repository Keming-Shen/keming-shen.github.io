07 自注意力机制

发表于2026-04-10|更新于2026-10-07|「CV」看得见的计算机视觉从神经网络到 Transformer
|浏览量:

同一个 token 在不同句子中具有相同的初始 Embedding（将 token 编号映射为可学习向量的表示），但其语义取决于当前上下文。逐位置 MLP 无法读取其他位置，循环递推则需要逐步传递状态。Attention（注意力机制）提供另一种计算方式：让每个位置根据当前特征，直接从一组可访问的位置中聚合信息。

检索系统可以帮助区分这项运算中的三个对象。例如，在搜索引擎中输入一个查询之后，系统会把它与每篇文档的标题、关键词等索引信息进行比较，按照相关程度排序，然后返回文档的内容。在这一过程中，涉及三类对象：查询（即用户的需求）、键（即用于匹配的索引）以及值（即真正返回的内容）。其中，键与值属于同一篇文档，但二者不必是同一种表示，例如，标题用于匹配，而正文才是需要阅读的内容。

Soft attention 将匹配与读取组合为可微分的加权聚合运算。与传统检索相比，它主要有以下两点区别：

  • Soft retrieval（软检索）。 与返回若干离散结果的检索操作相比，soft attention 为每个 Key 计算连续的匹配分数，将其归一化为权重之后，返回所有 Value 的加权平均。由于权重是分数的光滑函数，整个运算都可以求梯度，因此能够用反向传播进行训练。
  • 匹配特征与输出内容可以分别学习。 在 Transformer 的 scaled dot-product attention 中，Query、Key 与 Value 由输入经过不同的可学习线性投影得到。模型通过训练目标共同优化评分所用的特征和被汇聚的内容。

下图对比了两种检索方式：

在此基础上，self-attention（自注意力） 是指查询、键、值都来自同一个序列的情形：序列中的每个位置都会向其他所有位置发出查询，并汇聚它们的信息。这样一来，同一个 token 在不同的上下文中就可以得到不同的表示。这也是 Transformer 能够取代 RNN 递推结构的核心运算。

2. Q、K、V 的投影与点积

2.1 线性投影

在明确了注意力的计算步骤之后，接下来的问题是：查询、键和值究竟从何而来？设输入序列为 $X\in\mathbb R^{n\times d_{\mathrm{model}}}$，其中每一行是一个位置的特征。一个 self-attention 头会使用三组参数矩阵，分别计算出查询、键和值：

因此，$Q,K\in\mathbb R^{n\times d_k}$，$V\in\mathbb R^{n\times d_v}$。由于 Q 与 K 之间需要计算点积，二者的维度必须相同；而 V 的维度则可以不同。此外，这三组矩阵在所有位置上都是共享的。

以三位置序列为例，下图展示了三组投影的形状变化：

那么，为什么需要三组不同的投影，而不直接使用 $X$ 本身呢？先考察评分部分，将分数矩阵展开：

如果直接使用 $XX^\top$，那么分数矩阵一定是对称的，并且每个位置与自身的点积 $\lVert x_i\rVert^2$ 也往往偏大。相比之下，独立的 $W^Q,W^K$ 使得 $QK^\top$ 不必对称，也就是说，位置 $i$ 对位置 $j$ 的关注程度，可以不同于 $j$ 对 $i$ 的关注程度。这使模型能够表达有方向的查询关系，而不要求位置 $i$ 与位置 $j$ 以相同分数读取彼此。语法依存也常具有方向，但注意力分数并不预先规定某一种语法关系。更进一步地，即使分数矩阵是对称的，由于逐行 softmax 的分母各不相同，最终的权重矩阵一般也不对称。对于内容聚合部分，独立的 $W^V$ 则让“取回的内容”与“用于匹配的特征”相互解耦。

4.3 注意力权重可以说明什么

由于注意力权重图非常直观，它常常被用来“解释”模型的行为。但需要注意的是，权重只是当前层、当前头的混合系数，而最终的输出还取决于值向量本身、输出投影、残差路径以及后续的各层。例如，一个权重很大的位置，如果其值向量很小，或者在后续计算中被抵消，那么它对预测的实际贡献可能非常有限。对此，Jain 与 Wallace（2019）等工作专门进行了讨论。因此，注意力权重可以作为分析的线索，但不宜直接等同于特征的重要性。

5. 掩码：限定可访问范围

5.1 加性掩码

在默认情况下，注意力允许每个查询访问全部的键。然而，在实际任务中，有两类位置需要排除：一是为了对齐批次长度而补入的填充位置，二是自回归解码中尚未生成的未来位置。为此，掩码 (mask) 会在 softmax 之前修改分数：

由于 $e^{-\infty}=0$，被屏蔽位置的权重为零，而剩余的权重会自动在允许的位置之间重新归一化。相反，如果在 softmax 之后才把部分权重置零，那么剩余权重之和就不再为 1。具体而言，常用的掩码有以下两类：

  • Padding mask：屏蔽填充位置，使其不能作为键被读取。
  • Causal mask：在解码器的 self-attention 中，规定位置 $i$ 只能访问 $j\le i$ 的位置。例如，当长度为 3 时：

5.2 全部位置被屏蔽与填充查询

使用掩码后，仍需保证权重归一化有定义，并区分 Key 与 Query 上的填充位置。首先，每个有效的查询至少要有一个允许访问的键。如果某一行全部为 $-\infty$，普通的 softmax 就会得到 $0/0$，从而产生 NaN；而如果改用一个有限的极小值（如 $-10^9$），该行又会变成均匀分布，从而悄悄地读取了本应被屏蔽的位置。因此，在实现时应当明确地检测并处理这类行。其次，屏蔽填充位置作为键被读取，并不会让填充位置作为查询时的输出变为零，因此后续的池化和损失计算仍然需要按掩码排除它们（第 03 章）。

6. self-attention 与 cross-attention

在点积注意力中，Q 与 K 的特征维度必须相同，K 与 V 的位置数量也必须相同，但三者可以来自不同的序列。根据来源的不同，注意力可以分为以下两种。

self-attention中的三组向量都来自同一层的输入 $X$。在这种情况下，序列中的每个位置既会发出一个查询，也会提供一个键和一个值，因此输出的位置数与输入相同。由于它让每个位置都可以直接读取序列中的任意其他位置，任意两个位置之间的信息传递只需要一步，这正是它在处理长距离依赖时优于 RNN 的原因。

与之不同，cross-attention（交叉注意力）的查询来自一个序列，而键和值来自另一个序列。在翻译模型中，设编码器的输出为 $H$，解码器当前子层的输入为 $Z$，则有：

如果源序列长度为 $S$、目标序列长度为 $T$，那么权重矩阵的形状为 $T\times S$，输出有 $T$ 行，即每个目标位置都会汇聚一次源端的信息。在这里，$T$ 与 $S$ 可以不同，也不要求逐词配对。这正是第 06 章中 Bahdanau 注意力的缩放点积版本。

下图对比了两种注意力的数据流：

在原始 Transformer 中，编码器使用 self-attention；而解码器则先使用带 causal mask 的 self-attention 处理目标前缀，再使用 cross-attention 读取编码器的输出。由于完整的源句是已知条件，cross-attention 只需要屏蔽源端的填充位置即可。

7. 计算复杂度

最后，简要分析注意力的计算复杂度。对于长度为 $L$ 的序列，单头 self-attention 需要计算 $L\times L$ 个分数。因此，显式存储权重矩阵需要 $O(L^2)$ 的空间，而点积与加权求和的计算量为 $O(L^2d_k+L^2d_v)$；此外，Q/K/V 投影还需要 $O(Ld_{\mathrm{model}}d_k)$ 量级的计算。当序列较短时，投影和前馈网络在计算中占主导地位；而当序列很长时，二次项则会占据主导。

以 $d_{\mathrm{model}}=512$ 为例，下图对比了投影与注意力两部分的计算量随序列长度的变化：

序列增长时，这种二次复杂度会显著增加长文本与高分辨率图像的计算和存储需求。后续改进包括，稀疏注意力、线性注意力，以及保留稠密注意力数学运算、优化显存访问的 FlashAttention（第 11 章）。

需要区分的是，这里存在两个不同层次的并行性。一方面，在同一个注意力头内，所有查询位置都可以通过矩阵乘法同时计算，causal mask 只是限制了信息的访问，并不要求逐个位置执行；另一方面，autoregressive generation 必须等待前一个 token 被选定之后，才能确定下一步的输入。换言之，算子层面的并行性与生成步骤之间的顺序依赖，是两件不同的事情。
