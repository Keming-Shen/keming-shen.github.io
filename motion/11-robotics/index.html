11 人体动作与机器人运动控制

发表于2026-10-03|更新于2026-10-05|「Motion」3D人体动作生成3D 人体动作建模
|浏览量:

人体动作可作为机器人的运动参考，规定期望的姿态、空间轨迹和时间过程。运动控制根据机器人状态估计与参考运动计算驱动输出，使实际运动跟踪目标。人体序列通常仅包含运动学观测，未提供实现这些运动所需的关节力矩；机器人连杆比例、关节轴、质量分布和接触条件又与人体不同，因此人体数据需要经过形态重定向，并由满足动力学约束的控制器执行。

人体动作到机器人执行包含运动学生成、形态重定向与闭环控制三个层次。生成器定义行为分布，重定向在机器人配置空间中恢复几何对应，控制器则根据状态反馈求可实现的驱动输出。三者的可行集合依次受到语义与数据分布、机械结构、接触动力学和驱动器能力约束。上游输出只有进入下游的可执行集合，才能形成真实运动。

1. 人体与机器人的状态空间

状态空间的差异是重定向的起点。人体参数模型可能同时包含根位姿、身体关节、手指和形状参数，机器人则以刚性连杆、运动关节及驱动器描述结构。自由度数量、旋转轴顺序、关节零位和运动范围均可能不同，因此人体关节参数与机器人关节角通常不存在逐元素对应。

设机器人有 $n_a$ 个受驱动自由度，未固定于环境的基座称为浮动基座。配置空间局部写成 $\mathcal Q=\mathrm{SE}(3)\times\mathcal Q_a$，其中 $\mathcal Q_a$ 受关节类型与机械限位约束；广义速度 $v\in\mathbb R^{6+n_a}$ 属于配置流形的切空间。四元数用四个数存储三维旋转，因此配置数组与速度数组维度可以不同，积分必须保持单位四元数或等价的旋转流形约束。

人体参考使用帧索引 $t\in\{0,\ldots,T-1\}$，采样间隔 $\Delta t=1/f$；策略决策使用 $\ell$，底层伺服循环使用 $j$。三者通过物理时间戳关联，不能把一帧 motion、一次策略前向和一次力矩更新视为同一个时间步。下文动力学中的点号表示对物理时间求导。

关节名称相同也不意味着可以直接复制数值。一个数据集用父关节局部轴表示人体旋转，机器人模型可能使用另一组轴与零位。需要先校准坐标、参考姿态与关节对应，再使用机器人的正向运动学检验端点位置。

重定向目标需要体现任务相关的优先级。挥手侧重手部轨迹与风格，行走侧重足部支撑与根运动，搬运还要求保持手–物接触。形态差异可能使全部人体关键点同时匹配不可行，此时应优先保留与任务成功直接相关的几何关系。

当前状态本身也需要估计。关节编码器能够提供内部角度，却不能单独确定躯干在世界中的位置；惯性测量存在偏差，足接触判断也会受地面与噪声影响。控制策略接收的是传感器或估计器输出，训练时直接使用仿真真值会减少这一难度。真实设备中的追踪因而同时受控制策略与状态估计精度影响。

重定向是多目标约束优化：末端位置、根高度、姿态风格和关节限位可能互相竞争。时间参数化也属于可行性的一部分；将持续时间扩大为原来的 $\alpha$ 倍，沿同一几何路径的速度与加速度分别缩放为 $1/\alpha$ 和 $1/\alpha^2$。这会降低惯性项，却不会同比降低重力支撑需求，也不自动保证接触切换相容。形态、时间与动力学因此需要联合分析。

2.1 由人体关键点拟合机器人参考

ASAP 的重定向先拟合人体形状与整体比例，再选择人体关节和机器人连杆的对应。动作处理中，人体模型恢复世界关键点，机器人正向运动学把关节角和根变换映射到对应连杆位置；优化器最小化二者的平均位置差，同时更新关节角、根朝向与根位置偏移。

每次更新后将关节角截断到机械限位，并对时间序列做平滑。最终通过机器人表面确定地面高度，保存根运动、关节自由度与朝向参考。关键点匹配解决形态对应，限位和平滑解决参考的几何与时间一致性，驱动力则由后续控制器产生。

运动学重定向以参考的几何相容性为目标，动力学可行性还取决于速度、加速度、可用驱动力和接触力。相同姿态序列在不同时间尺度下可能需要显著不同的力矩；固定足部位置的几何约束也不能保证地面能够提供所需支撑。

3.2 接触相容与驱动边界

5. 大规模参考追踪与失败恢复

执行指定动作需要参考条件下的精确追踪。PHC 在大规模动作数据上训练实时模拟人体控制器，采用 progressive multiplicative control policy（PMCP）逐步增加策略容量，将后续 primitive 分配给尚未掌握的困难片段，再通过组合策略协调已有能力。独立学习的恢复行为扩展了倒地等偏离参考状态下的控制范围。

参考误差需要在正确坐标下评价。仅对齐根位置后计算局部关节误差，会隐藏整体漂移；仅计算世界关键点，又可能把轻微整体偏移与严重姿态错误混在一起。局部姿态、根轨迹和世界末端误差分别保留了这三个层次的信息。

参考附近的低误差训练只能覆盖局部吸引域。倒地、错误接触和较大根偏移改变可行的恢复路径，可能要求先偏离参考再重建支撑。PHC 通过困难样本和恢复经验扩展状态覆盖，使策略有机会返回可追踪区域；有限测试中的恢复成功仍不能等同于全状态空间的稳定性保证。

PHC 首先处理物理模拟人体，其追踪与恢复机制为后续机器人控制提供了思路。机器人具有不同的自由度、质量分布与驱动器，参考状态、动作输出和环境转移都要随形态改变。

6. 遥操作接口与仿真现实对齐

参考追踪接口也可以接收实时的人类输入，形成遥操作：操作者持续提供目标，机器人利用自身反馈执行。OmniH2O 用人体运动学姿态作为统一的全身控制接口，连接不同人类输入方式与人形机器人。人体姿态先经过重定向，控制策略再利用机器人实际可获得的观测维持执行。

OmniH2O 先训练能够读取完整仿真状态的 privileged teacher，再将其行为蒸馏到只使用可部署观测的 student policy。Teacher 利用完整状态降低追踪学习难度，student 通过本体感知与历史观测推断隐含状态，从而满足真实设备的观测限制。

遥操作持续接受人类反馈，也可以产生后续任务学习所需的机器人演示。追踪器将姿态目标落实为运动，操作者负责目标修正；自主策略则需要从观测中承担这部分决策。演示质量与自主任务成功对应这条链路中的不同阶段。

6.1 观测、策略网络与关节动作

以 ASAP 的 23 自由度 G1 配置为例，部署策略的单步观测包含基座角速度三维、投影重力三维、关节位置与速度各 23 维、上一动作 23 维，以及一维参考相位，共 76 维。加上四步历史，输入为 $[B,380]$。历史提供近期速度与响应信息，参考相位标识动作的时间进度。

策略采用 $380\to512\to256\to128\to23$ 的 MLP，隐藏层使用 ELU。输出是 23 维关节位置偏移，经缩放加到默认关节姿态上，再由 PD 控制器产生截断力矩。价值网络具有独立参数，并可读取基座线速度与参考关键点等特权信息；这些额外状态辅助训练，策略输入仍保持部署可得的观测。

6.2 残差动作的仿真对齐

相同观测与动作接口下，仿真和真实设备仍可能具有不同转移动力学。ASAP 先在仿真中预训练追踪策略，再根据真实执行轨迹学习 delta action model，以残差动作修正仿真响应。在对齐后的仿真中微调策略，可将真实系统的响应差异引入训练。

设真实策略轨迹记录为 $(\xi_\ell^r,a_\ell^r)$，残差模型根据仿真状态和记录动作产生 $\Delta a_\ell$，仿真器执行 $a_\ell^r+\Delta a_\ell$。训练以真实状态轨迹为匹配目标，并限制残差动作大小；它修正的是动作空间中的响应差异，而不是直接重写人体参考。

delta action model 训练完成后保持固定，新的追踪策略输出 $a_\ell$，对齐仿真使用 $a_\ell+\Delta a_\ell$ 产生下一状态。策略在这个环境中继续学习，逐渐适应真实设备的响应。最终部署只运行优化后的追踪策略与设备反馈，残差模型承担训练中的仿真对齐。

动力学差距可能来自电机响应、摩擦、质量估计、关节迟滞与控制延迟。domain randomization 让策略适应一组变化，数据驱动对齐则尝试描述真实设备中观测到的差异。两者都依赖合理的数据范围；没有观测到的高速状态、负载或地面条件，仍可能超出已学模型。

真实数据的时间对齐影响残差模型学到的内容。电机响应与传感器延迟会使控制动作和观测状态错开；配对错误时，模型可能用相位补偿解释误差。因此，时间同步与动力学对齐需要共同处理。

7. 运动追踪接口与任务语义闭环

可追踪行为范围扩大后，同一底层控制器可以接收来自遥操作、运动生成器或任务策略的参考。SONIC 通过扩展运动数据、网络容量与训练计算规模学习通用全身追踪，并利用统一控制接口连接不同上游目标。其核心输出仍为满足机器人动力学的控制行为，上游参考则承担任务与空间条件的组织。

任务闭环基于环境状态与执行结果更新运动目标。以苹果取放为例，视觉定位提供对象与容器状态，操作策略确定抓取和放置目标，运动追踪器执行参考；接触失败或目标移动后，上层策略需要修正后续计划。任务成功因而由对象状态转移定义，无法仅用关节追踪误差衡量。

低层反馈由本体感知与接触估计修正执行误差，高层反馈由对象状态与任务进展更新参考。对象移动改变抓取目标时，任务层需要先更新手部轨迹；低层控制器只能在可执行集合内追踪该轨迹。较低的关节误差并不蕴含正确的对象状态转移，两个闭环必须共享时间戳、目标版本与接触状态。

真实部署还需要处理输入噪声、动作切换、能耗、接触安全和设备故障。在姿态空间中过渡平滑的两段参考，可能具有不兼容的足接触或很大的速度差。动作选择接口应检查当前物理状态与下一段参考的起点，避免控制器在不合理条件间强行追踪。

地形与负载变化同时影响规划与控制。台阶要求更新足部落点和抬脚高度，额外负载改变惯性与支撑力分配；这些信息需要进入参考规划和控制状态，使落脚位置、运动速度与驱动输出随执行条件调整。

10. 追踪、恢复与任务执行的评价

控制评价连接参考与执行结果。局部关节误差衡量姿态，根轨迹误差衡量整体运动，世界末端误差衡量手足是否到达目标；力矩饱和、能耗和接触滑动则反映实现这些轨迹的代价。一个控制器可能保持很小的局部姿态误差，同时发生根漂移，因此各项误差需要保留各自的坐标含义。

参考追踪、受到扰动后的恢复与完成物体任务，是三个不同层次。恢复取决于策略是否见过偏离参考的状态，任务成功还取决于感知、对象状态与重规划。低层反馈修正关节和姿态，高层反馈修正目标与行为，两个闭环共同决定系统在变化环境中的能力。

10.1 多率闭环与参考时序

参考刷新、策略决策和伺服反馈具有不同带宽。作为说明性量级，高层规划或参考更新可工作在 20–50 Hz，而关节 PD 或力矩伺服可工作在 500–1000 Hz；实际频率由硬件、通信与策略设计决定，不能将这一范围作为所有系统的共同配置。策略网络本身还可能采用独立的中间频率。

令墙钟时间为 $\vartheta$，策略周期为 $\delta_\pi$、伺服周期为 $\delta_c$。第 $j$ 个伺服时刻 $\vartheta_j=j\delta_c$ 读取最近的策略目标，持续使用新测量状态计算反馈。参考帧则根据 $t\Delta t$ 的时间戳插值，而非按每个伺服周期递增一帧。保持或插值的位置目标与持续更新的反馈必须分开：高层目标暂时不变时，底层力矩仍可响应扰动。

较高伺服频率减少采样造成的反馈滞后，但无法消除过期目标、不可行接触切换或感知延迟。参考缓冲必须保留足够的未来轨迹，同时在目标变化后允许修正尚未执行的片段；否则更平滑的播放可能伴随更迟的任务响应。多率同步最终需要维护位置、速度、接触模式及时间戳的一致性，而不是仅提高控制循环的次数。

动作生成的后训练（post-training）在预训练生成器上，利用质量评分或偏好监督进一步调整条件分布。去噪、重建与 token 预测目标主要拟合训练数据，而语义一致性、接触稳定性、时间连续性和感知质量分别对应下游评价要求。两类目标之间的差异构成后训练的主要动机。例如，同一句“一个人缓慢坐下”可以生成语义正确但脚部滑动的动作，也可以生成接触稳定却突然加速的动作。区分上述质量差异，需要针对相应运动属性构造反馈信号。 反馈信号具有明确的评价范围：文本检索衡量跨模态语义对应，人工偏好描述感知排序，真实性分类区分采集与生成分布，脚滑惩罚约束接触阶段的运动学误差。奖励函数对这些属性的敏感性决定优化方向，梯度估计与参数更新机制则决定反馈如何作用于生成分布。 1. 监督目标与动作质量目标在动作 token 模型中，监督目标是降低标注序列的负对数似然；在扩散模型中，是降低噪声或 clean motion...
