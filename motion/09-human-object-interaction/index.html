CH-09 人体与物体的交互动作

发表于2026-10-03|更新于2026-10-08|「Motion」3D人体动作生成3D 人体动作建模
|浏览量:

以搬运箱子为例，手部需要在抓握阶段随物体运动，身体姿态也要与足部支撑相协调。若分别生成人体与物体的轨迹再将二者组合，即使两条轨迹各自平滑，也可能出现手部脱离表面、身体穿透物体或释放后物体漂移。问题在于，接触会改变允许的相对运动：接近、抓握、运输与释放具有不同的约束，不能仅靠轨迹平滑性统一描述。人体与物体交互动作生成（Human–Object Interaction Generation）因此需要联合建模人体姿态、物体位姿与接触拓扑，使连续运动与接触阶段保持相容。

这种耦合依赖两个层次的空间信息：物体局部几何决定可接触区域，物体位姿决定这些区域在世界坐标中的位置。语言指令再将局部接触与全局任务联系起来。例如，将椅子搬到桌旁，既要求物体到达目标，也要求人体在搬运过程中维持抓握与支撑。建模由此围绕任务语义、空间轨迹和局部接触展开，并根据已知条件选择物体运动引导、稀疏路标联合生成或分层轨迹规划。

上述表示适用于刚性物体。对于其他结构的对象，门与抽屉还需要铰链角度或滑动位移，布料则需要描述非刚性形变。交互对象的结构改变了状态空间和接触约束，因此刚体搬运、铰接物体操作与柔性物体操作需要不同的表示与模型。

人体与物体交互常缩写为 HOI，但同一缩写也用于静态图像中的人–物关系检测。这里的输出是三维、随时间变化的运动，必须区分其表示、监督与评价协议。

3. 物体运动引导与中间手部表示

物体轨迹规定了操作对象的运动，却没有直接确定肩肘、躯干与下肢应如何协同。手部作为搬运中的主要接触末端，可将这一问题分解为局部接触与全身协调两个层次。OMOMO 用完整物体轨迹引导人体动作：第一阶段根据逐帧物体位置与旋转生成手部位置，第二阶段根据经过接触处理的手部轨迹生成全身动作。

两阶段之间只传递左右手的三维轨迹，因此物体对全身的影响被压缩到六维手部位置中。局部接触修正能够直接调整操作末端，但未必保留物体形状对前臂、躯干和下肢的全部限制。不可达的手部目标与不连续的轨迹会沿条件通道传播，第二阶段的误差因而同时取决于可达性和训练、推理条件分布之间的偏移。

手部可达性与全身无碰撞是不同的几何条件。例如，末端到达目标表面时，前臂仍可能穿过椅背，躯干也可能与搬运路径上的物体相交。因此，手部中间表示需要与全身几何约束配合。

3.1 六维手部轨迹与全身去噪

第一阶段将左右手掌位置拼接为 $H\in\mathbb{R}^{B\times T\times6}$，其中 $B$ 为 batch size，$T$ 为动作帧数。每帧物体表面的 BPS 位移与物体中心位置构成时序几何条件，去噪网络据此预测未加噪的手部轨迹。第二阶段采用二十四个关节的位置与二十二个关节的 6D rotation，每帧共有 $24\times3+22\times6=204$ 个特征通道。左右手掌位置作为已知条件送入全身网络，其余位置与旋转通道由网络预测。这里的特征维度由表示形式决定，不等于人体的独立物理自由度。

两个网络分别训练，均预测 clean motion，并在有效帧上计算 $L_1$ 重构损失。第二阶段训练时使用真实手部轨迹，推理时使用第一级生成并经接触修正的轨迹；这一条件分布差异是级联误差的重要来源。

接触修正在物体表面确定局部抓握点，并利用物体的逐帧刚体变换更新接触阶段的手部位置。修正后的轨迹写入全身状态的已知条件通道，再进行第二阶段扩散采样。物体几何因而通过受约束的手部轨迹传递到全身运动。

相同物体轨迹下的对比突出中间接触表示的作用：单阶段模型与两阶段模型的手–物相对位置不同，连续帧又将局部接触偏差与全身姿态调整联系起来。手部贴合改善后，还需检查肩肘可达性、全身碰撞和足部支撑；这些条件没有全部包含在手部中间表示中。

4. 稀疏路标条件下的联合生成

完整物体轨迹预先规定了搬运路径与时序，限制了生成器的规划范围。当输入仅包含语言意图和少量路标时，物体运动本身也成为未知量。CHOIS 将人体、物体与接触状态拼接为联合序列 $Z$，在物体几何、初始状态和稀疏路标条件下同步生成这些变量。

4.1 人体、物体与接触的联合状态

在含接触监督的配置中，CHOIS 每帧拼接三类变量：物体中心三维位置与九维旋转矩阵，人体的二十四个关节位置与二十二个关节六维旋转，以及四维接触标签。因此 $Z^{(0)}\in\mathbb{R}^{B\times T\times220}$，其中人体部分为 204 维。位置按训练数据的范围归一化，物体旋转可以相对于选定参考帧表示；反归一化与参考旋转恢复把预测送回几何空间。

物体几何采用 $1024\times3$ 的 BPS 位移，展平后经过 $3072\to512\to256$ 的 MLP，再沿时间复制。初始物体状态、末端物体位置、若干水平路标与可用的初始人体姿态，分别占据联合状态中的已知通道。

4.3 接触引导与反向采样

推理从联合高斯噪声出发，每步读取相同的已知条件。接近去噪结束时，预测接触标签选择手部接触阶段，引导项检查手与物体的间隙、物体局部坐标中的手部相对方向、足部高度及物体穿地。条件特征缩小生成范围，几何梯度进一步修正当前预测，两者承担不同的作用。

CHOIS 的引导以几何协调为目标。物体质量与抓握力没有直接进入位姿序列，因此重箱子与轻空箱可能得到相似动画；实际搬运还需要控制器根据负载、接触与平衡条件调整运动。

路标必须满足空间和时间上的可行性。具体而言，相邻目标间距与时间间隔共同决定所需速度，目标位置与物体尺寸共同决定避障条件。规划阶段应排除相互矛盾的输入约束，避免将不可行路径交给局部动作生成器。

5. 接触数据与多任务建模

上述接触监督与联合条件依赖配对数据，因此数据质量直接影响模型学到的关系。物体位姿、几何、接触部位、接触阶段与文本，都需要在同一时间轴上对齐。手与物体相互遮挡恰好发生在最需要精度的位置，人体拟合也可能在这些帧产生穿透或不可靠的手指姿态。交互数据的成本由捕捉和这些后续处理共同构成。

InterAct 将异构三维人–物交互数据统一为共同表示，并修正接触与手部姿态，支持不同条件下的交互生成。跨来源整合需要统一骨架、物体资产、尺度、时间采样和坐标约定；否则来源相关的几何偏差会被模型误学为运动模式。

对物体几何进行 Data Augmentation（数据增广）时，接触对应、手部目标和局部参考系必须随物体表面一起更新。例如，箱子宽度改变会移动双手抓握区域，仅缩放物体而保留人体轨迹，会把错误接触写入监督。即使几何关系修复，新增质量与惯量也不会由表面变换自动确定，因此形状增广扩展的是几何条件覆盖。

原始采集、清理和几何增广提供不同的信息。替换物体形成的样本共享原动作和捕捉误差，却可以增加几何条件的覆盖。跨物体实例通常保留相似抓握结构，跨类别则可能需要新的接触方式，两者对应不同的泛化难度。

手部表示决定交互的精细程度。手腕位置适合搬运的粗粒度协调，指尖捏取与旋拧则需要手指自由度及相应接触数据。密集人体网格描述表面形状，接触力仍是另一类需要观测或求解的状态。

6. 轨迹规划与细节动作的解耦

从完整物体轨迹到稀疏路标，模型承担的规划工作逐步增加。若进一步只指定初始状态和目标，路径本身也成为主要未知量。DecHOI 为此将全局路径生成与细节交互动作生成分开：轨迹生成器根据指令、几何、初始状态与目标生成路径，动作生成器再沿这些路径补充人体关节、物体旋转和局部接触。

6.1 两级条件扩散与密集轨迹条件

首先，Trajectory Generator（TG）保留初始人体与物体状态，以及末帧物体目标位置，结合 BPS 几何特征与 CLIP 文字条件，预测人体根与物体的三维路径。随后，Action Generator（AG）把这两条路径写入全部物理帧的已知位置通道，再生成关节与物体旋转；文本通过 cross-attention 调节两个生成器。TG 以 clean trajectory 的 $L_1$ 误差训练，AG 以完整状态重构误差训练，并通过 FK 约束手足位置。

6.2 手足与物体几何的对抗监督

DecHOI 的判别器读取由 FK 恢复的双手、双脚位置，以及逐帧变换后的物体表面点。它采用 hinge loss 区分真实和生成序列，AG 则提高生成序列的判别分数。这样的输入使局部接触间隙与足部运动进入数据监督，而不必把所有误差压缩为一个全身姿态距离。判别监督约束运动统计，物体负载、接触力与摩擦可行性仍由动力学决定。

分层生成还可以与动态路径规划结合：环境或目标变化后，先更新剩余路径，再生成相应动作。重规划必须以当前已执行状态为边界条件，并维持位置、速度与接触状态的连续性，才能形成可连续执行的运动。

长序列拼接需要传递混合状态：连续部分包括人体配置、物体位姿与速度，离散部分包括接触集合及抓握对应。仅对重叠帧做欧氏插值，既可能破坏旋转流形，也可能跨越不相容的接触模式。若前段终点仍处于承重抓握，后段必须维持相同连接或显式生成释放与支撑转移，才能避免无物理依据的模式跳变。

目标坐标需要绑定明确的物体参考点，例如几何中心、底面中心或指定放置区域。输入与评价采用不同参考点会引入系统偏差。数据接口应同时保存资产坐标到标准物体坐标、标准物体坐标到世界坐标的变换，使目标、轨迹和表面几何共享一致定义。

9. 联合运动的评价

人体与物体的联合动作，需要分别评价任务条件符合度、接触与碰撞一致性，以及人体本身的运动质量。其中，文本一致性、目标位置和路标误差衡量任务条件；接触间隙、相对滑动和人–物穿透衡量几何关系；脚滑、速度突变与动作分布衡量人体运动。分项指标可以区分路径偏差、接触失效和姿态异常等误差来源。

无符号表面距离无法区分接触与浅层穿透，接触评价还需要表面法线、带符号距离或体积相交检测。抓握稳定性应在物体局部坐标中衡量相对滑动，足部支撑则在地面参考系中衡量速度。

交互模型对新对象的泛化，需要区分物体实例、类别与物理参数的变化。例如，未知椅子实例仍可能保留熟悉的椅背与抓握结构，未知物体类别则可能需要新的接触方式。物体质量、关节自由度和手指操作进一步改变任务状态空间。运动学模型学习人体与物体的位姿关系，力与摩擦约束则属于执行层，二者共同决定交互在真实环境中的可行性。

随机生成的分布也需要关注尾部。均值、分位数与严重穿透率分别反映总体表现、稳定性和失败风险；候选筛选会改变这些统计，因而应与生成器本身的输出分布区分。
