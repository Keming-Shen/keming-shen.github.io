10 人体与场景的交互动作

发表于2026-10-03|更新于2026-10-05|「Motion」3D人体动作生成3D 人体动作建模
|浏览量:

人体与场景交互（Human–Scene Interaction，HSI）研究人体运动与环境几何、支撑关系和对象语义之间的耦合。以走向指定椅子并坐下为例，系统需要依次完成语言目标定位、路径规划和接触动作生成。动作类别正确并不足以保证任务成功：目标对象错误、路径碰撞或坐面接触失配，分别对应语义、导航和局部交互层面的失败。

环境几何通过可达性、碰撞和支撑约束改变允许的动作集合。低矮坐面改变髋膝配置，狭窄通道限制身体包络与转向空间，躺卧则要求连续身体区域获得支撑。这些变化要求场景信息进入运动生成过程。与搬动物体时生成物体轨迹的任务相比，静态场景交互主要利用已知环境，决定人体能够到达、应该接触和需要避开的区域。

场景交互与物体交互有交叠。坐在固定椅子上主要涉及人体与静态环境的关系，搬动椅子则还要生成物体状态。两个人抬桌子穿过房间同时包含人–人、人–物和人–场景关系。按交互实体拆开研究有利于分析，但真实任务经常需要多个关系同时成立。

场景观测完整性决定条件变量是否可直接视为已知。完整地图支持确定几何上的规划，在线 RGB-D 则只观察可见表面；此时规划应依赖场景后验或带不确定性的地图。未观测区域既不能直接归为自由空间，也不能由生成先验的高置信度补全自动获得真实性，需要通过新观测更新可行路径与目标判断。

2. 距离场、接触与身体尺度

路径和接触都依赖人体与环境之间的距离，因此首先需要可计算的场景几何接口。带符号距离场（Signed Distance Field，SDF） $\phi_S(p)$ 将空间点映射为到场景表面的距离，并用符号区分内部与外部。这里约定障碍物外部为正、内部为负，表面为零；实现采用相反符号时，损失与阈值也要对应修改。

非穿透与接触目标分别约束人体不得进入障碍内部、指定身体区域应接近目标表面。无穿透的悬空人体仍可能违反支撑条件，而与错误椅子接触的人体仍可能违反语言目标。因此，几何约束与目标语义应作为独立条件共同参与建模。

逐个网格顶点检查适合精细接触，导航还常需要计算成本较低的人体几何近似。把人体近似为圆柱或胶囊后，可以通过扩张障碍物求可通行区域。例如，取 $y$ 为竖直轴，将障碍投影到水平面，并构造二维距离场 $\phi_{\mathrm{nav}}(x,z)$；若身体在该平面的圆形包络半径为 $r$，则 $\phi_{\mathrm{nav}}(x,z)-r$ 给出根位置的水平安全裕量。这里的障碍集合不包含支撑地面，地面高度与足部支撑另行检查。这个代理把身体体积纳入路径检查，但抬起的手、侧身的肩膀和弯曲的膝盖仍可能超出固定包络。

扫描场景也不一定形成封闭的实体。薄板、缺失表面和重建孔洞会让距离场的“内部”定义不稳定；离散网格插值则可能漏掉狭窄障碍。实际接触处应结合原始网格、表面法线和足够密集的人体点检查，不能仅依赖一个低分辨率距离场值。

2.1 SDF 梯度与几何误差反传

精确欧氏 SDF 在光滑表面附近、最近点唯一且函数可微的区域满足 Eikonal 条件 $\|\nabla\phi_S(p)\|_2=1$。其梯度等于最近表面的外法线方向；表面点上即为单位法向量。medial axis、棱角及最近点不唯一处可能不可微，不能在这些位置假设存在唯一平滑法向。

离散插值与神经近似场通常不严格满足单位梯度条件。若 $\|\nabla\phi_S\|$ 偏离一，相同距离残差会产生不同尺度的更新；梯度方向错误还可能将人体推向错误表面。Eikonal 正则约束梯度模长，但不足以独立确定正确表面和法向，仍需边界或距离监督。低分辨率距离场因此可以作为快速引导，精细接触应结合原始几何和可靠法向复核。

法向也约束接触姿态：脚底接近地面时，其朝向仍可能倒置；背部接近墙面时，也未必形成预期支撑。距离、身体表面方向与接触部位共同定义局部几何，而支撑力是否可行还需要第十一章的接触动力学。

整场景距离场通常只保留最近表面距离，不保留对象身份。目标椅子紧邻桌子时，针对整场景的接触损失可能将人体吸引到非目标表面。对象专属距离场或实例索引用于指定接触对象，整场景距离场用于无碰撞约束；两者的几何查询范围应明确区分。

3. 场景约束对人体恢复的作用

场景几何可以为三维人体恢复提供观测以外的约束。单目图像存在深度与遮挡歧义，坐姿人物的腿部和骨盆尤其容易被家具遮挡。仅依赖二维重投影误差时，多种三维姿态都可能解释同一图像，其中部分解会穿过地面或家具。

人体恢复与动作生成共享场景几何接口，但推断方向不同：恢复任务根据图像与场景估计已发生的运动，生成任务根据场景与目标构造新的运动。共同坐标系、实际尺度及接触部位是两类任务计算几何损失的前提。

由恢复结果构成的数据还要区分真实测量与拟合标签。经过场景优化的人体参数可能更合理，却仍受到传感器噪声、遮挡和模型形状的影响。把所有拟合结果当成无误差的接触真值，会使生成器继承其中的偏差。训练时可以使用置信度、质量筛选与独立接触校验，减少异常样本的影响。

大场景常采用人体附近的局部裁剪来降低点云规模。裁剪中心如果随人体变化，生成结果需要变换回共同世界坐标，目标点与场景点也必须使用相同变换。不同窗口的局部坐标接缝错误，会表现为根轨迹跳变或目标漂移。记录窗口原点、朝向和尺度，能够让局部感知与全局规划保持一致。

4. 语言定位与场景动作配对

几何条件能约束人体的位置，要学习语言驱动生成，还需要把场景、目标描述与完整动作配成训练样本。HUMANISE 将已有动作与三维室内场景对齐，并提供描述目标对象及空间关系的语言。其主要动作类型包括行走、坐下、站起与躺下，将动作类别、目标对象与空间指代共同纳入生成条件。

配对过程本质上是在场景内求满足动作接触结构的空间配准。坐姿末端与椅子中心重合只约束少量平移自由度，坐面高度、身体朝向、足部支撑与整个接近过程的无碰撞性仍是独立条件。几何筛选决定新增样本是否保留原动作的约束结构，也决定训练分布中是否混入不相容的场景—动作组合。

对齐生成的数据与现场捕捉存在分布差异。真人会根据局部障碍调整身体，而一个原先在空旷空间记录的动作，即使终点适合椅子，接近阶段也可能缺少必要的避让。因此，数据对齐适合提供结构化监督，却不能替代所有真实场景中的行为变化。

4.1 场景与语言的条件融合

数据处理对场景和人体采用同一个坐标变换，采样场景点，并把可变长度动作通过 padding 对齐为固定窗口；padding mask 使补齐帧不参与动作编码和重构。根朝向转换为六维旋转，身体关节保留轴角参数，根平移、根朝向和身体姿态组成每帧的动作向量。

可变点数的场景与可变长度的文本首先映射到共同特征宽度。Point Transformer 将点云编码为 512 维 scene token，BERT 的 768 维 token embedding 经线性层投影到相同宽度。两类 token 拼接为 $[B,N_s+N_l,512]$ 后进行注意力融合，其中 $N_s$、$N_l$ 分别为场景与语言 token 数。场景 token 与对应坐标聚合为场景向量，语言分支使用首个 token 的特征；二者结合人体形状参数，得到 512 维条件 $C$。辅助回归头由 $C$ 预测目标对象中心，使 language grounding 获得显式空间监督。

语言定位还需要分清几何近邻与语义关系。“门旁的椅子”不一定是距离人体最近的椅子；“桌子后面的椅子”中的“后面”还可能采用观察者视角或桌子自身方向。训练标注应说明参考系，测试时也要区分单一候选与多个相似候选对象。

描述同一目标时，还可能存在多个等价路径。人物可以从桌子的左侧或右侧接近椅子，坐下时也可能先转身或侧步。这些路径都可能到达目标并避开障碍，偏离某一条参考路径不必然意味着任务失败。若指令明确要求“从桌子左边绕过去”，路径方向就成为受控条件，生成分布相应收缩到满足该方向的运动。

5. 运动原语与长时序策略

局部交互与长时路径具有不同时间尺度。Motion primitive（运动原语）将短时动作编码为可组合的生成单元，长序列因而可以通过滚动选择 primitive 构建。DIMOS 在已学习的 primitive latent space 中训练场景感知策略，根据当前人体状态、局部环境和目标选择下一段运动，并衔接导航与落座等交互阶段。

导航网格为全局路径提供可通行路点，局部策略再决定如何运动。两者有不同的空间分辨率：全局规划可以避开大件家具，局部身体仍可能在拐角处碰撞。路径搜索结果需要与人体尺寸、可转向范围和动作原语的运动距离相匹配。

原语数据的分布影响策略的动作选择。行走、坐下和躺下具有不同的支撑与阶段关系，DIMOS 因而组织行走先验和交互先验，并使用对应的导航与交互策略。生成先验提供候选片段，奖励和终止条件决定片段如何朝任务目标组合。

滚动生成会将当前片段的误差传入下一次决策。因此，后续策略必须读取实际生成状态，持续修正根位置和朝向偏差；始终使用理想参考初始化片段，会使规划过程失去状态反馈。

导航与落座的切换条件需要表达接近方向。只用根位置到椅子中心的距离作为终止信号，会让人物可能从椅背一侧进入落座阶段。更完整的切换检查可以包含目标表面、朝向、相对速度以及足够的转身空间。人体体型改变后，这些量也会变化：同一椅子对不同腿长可能需要不同终点和膝关节范围，不能只把原动作整体平移过去。

6. 可供性作为定位与动作的接口

路径规划确定接近过程，局部交互还需要指定人体与环境的对应区域。Affordance（可供性）描述环境支持某种行为的条件，例如坐面支持落座、空旷地面支持行走。它与动作类型、人体尺度和当前占用状态有关，可作为对象语义与局部几何约束之间的中间表示。

基于这一中间监督，两阶段模型分别学习交互区域分布与条件动作分布。第一阶段 ADM（Affordance Diffusion Model） 根据语言和场景生成可供性图；第二阶段 AMDM（Affordance-to-Motion Diffusion Model） 根据文字、场景与预测图生成运动。语言目标由此与关节附近的空间区域联系起来，动作生成器获得比一个全局场景向量更明确的几何条件。

6.1 可供性与动作的张量接口

预处理在人体轨迹附近裁剪场景，采样 8192 个点，并计算每个场景点到二十二个关节轨迹的最近距离。连续关节配置选择骨盆、双脚、颈部和双手六个通道，得到 $A\in\mathbb{R}^{B\times N\times6}$。关节位置生成配置将动作展平为 $[B,T,66]$，保留二十二个关节的三维运动。

ADM 中，带噪图、每点三十二维场景特征、CLIP 文本向量与一百二十八维 diffusion-step Embedding 按点拼接。点级 MLP 先提取局部特征，再将全场景均值送回每个点，使局部位置与全局上下文同时进入图预测。最后的线性层恢复六个关节通道。

AMDM 将场景坐标与可供性图编码为 spatial token，投影到 512 维；带噪动作也映射到同一宽度。diffusion-step token、text token、spatial token 与 motion token 拼接为 $[B,2+N_g+T,512]$，经过位置编码和五层、八头 Transformer。padding mask 屏蔽补齐动作，输出保留对应动作帧的 token，再映射回六十六维关节位置。

Affordance 随环境状态变化。桌面占用会改变放置区域，人体尺寸变化会改变落座的可达范围。仅编码静态点云的表示无法完整表达未知占用、物体可移动性与支撑能力；动态场景需要将对象状态和感知不确定性共同纳入定位与规划。

7. 算例：点路径与身体碰撞包络

固定圆形身体代理将配置空间碰撞化为障碍物与半径圆盘的 Minkowski sum。对半径 $r=0.2$ 米的代理，根路径的可行条件为 $\phi_{\mathrm{nav}}(p)-r\geq0$。矩形障碍算例比较直线路径与指定绕行路径，分离路径长度和几何可行性这两个目标。

运行结果：

绕行增加路径长度，但将最小身体裕量从负值变为正值。精确圆盘膨胀在矩形拐角处形成圆弧，图中的扩张包围盒则是保守近似。该结果说明路径规划必须发生在考虑身体体积后的自由配置集合中；关节化人体的包络随姿态变化，单一根位置距离仍只是高维碰撞约束的低维近似。

8. 算例：时间聚合保留区域而丢失顺序

时间最大聚合将轨迹映射到访问区域的等价类。对一维关节轨迹及其时间反转，空间样本集合完全相同；使用高斯距离核后，每个场景点的最大响应因而不变。该低维算例直接检验聚合映射的不可逆性，而不依赖网络容量或训练误差。

运行结果：

两条起点相差 $1.4$ 米的轨迹得到逐点相同的聚合图，构成非单射性的直接反例。任何仅接收该图的确定性解码器都无法唯一判断原始方向；文本或历史条件可以选择兼容轨迹，却不能使已丢失的顺序自动重现。这是表示的信息压缩边界，并不等价于对物理因果关系作不可逆性的普遍断言。对先绕行再落座等组合任务，应额外评价阶段顺序与持续时间。

9. 场景任务的分层评价

场景任务的误差可按定位、导航和交互分层观察。目标对象准确率衡量指令是否落在正确椅子上；路径碰撞与长度衡量接近过程；终点、身体朝向、坐面接触和网格穿透衡量落座过程。定位正确而身体背对目标，与运动自然但坐错对象，分别要求修正空间条件与语义定位。

点云与网格提供不同精度的几何接口。最近点距离受点云密度影响，网格距离更适合检查接触附近的细小间隙；带符号距离场适合高效检测穿透，但薄板和缺失表面会影响内外定义。评价采用的表面、采样密度与符号约定，应与所描述的接触关系一致。

场景观测也决定规划条件。完整扫描可以提供确定的障碍集合，局部感知中的空缺则可能来自自由空间或遮挡。将未知区域纳入状态表示，并在必要时继续观察，能够避免把“没有测到障碍”等同于“可以通过”。

AffordMotion 的部分结果呈现交互区域正确但身体朝向不符的误差，反映了空间接近关系与完整交互状态之间的差异。除目标区域外，评价还应保留朝向、阶段和持续时间，并覆盖未知布局、相似对象与组合指令。
