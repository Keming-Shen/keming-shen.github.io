07 动作理解与生成的统一建模

发表于2026-10-03|更新于2026-10-05|「Motion」3D人体动作生成3D 人体动作建模
|浏览量:

动作理解与生成的统一建模在共享系统中估计动作到文本与文本到动作的条件分布，并进一步组织预测、补全等任务。共享运动表征可以减少任务间重复学习，共享语言接口则允许任务指令控制输入与输出语义。然而，两种模态的统计结构并不相同：文本通常由离散 token 构成，人体运动则是受几何与时序约束的连续信号。

统一建模的关键由此分为三个层次：首先确定运动进入语言上下文的表示形式，其次通过模态标记与 attention mask 区分条件和目标，最后为不同输出定义相应的概率模型。离散表示将动作压缩为有限词汇，可使用词表分类；连续表示保留 latent vector，需要扩散或 flow matching 等连续生成头。MotionGPT、MotionGPT3 与 LLaMo 分别体现了这几种设计。

本文以 $t\in\{0,\ldots,T-1\}$ 表示物理运动帧，采样间隔为 $\Delta t=1/f$；压缩后的 motion token 用位置 $\ell\in\{0,\ldots,N-1\}$ 标记。$K$ 仅表示 codebook 大小，离散扩散步用 $k\in\{0,\ldots,N_d\}$，连续 flow 时间用 $s\in[0,1]$。生成一个 latent 所需的扩散或积分步数，与该 latent 解码后覆盖的物理帧数是相互独立的量。

1. 双向条件分布与共享模型

1.1 两个方向并非确定的互逆变换

设动作序列为 $X$，描述为 $Y$，文本生成动作建模 $p(X\mid Y)$，动作生成文字建模 $p(Y\mid X)$。一个文字条件通常对应多种动作实现：步幅、手臂摆幅、转身速度和整体风格可以不同。一个动作也可以拥有多个正确描述，其中有些概括整体行为，有些只强调局部事件。

这是一种多对多的条件关系。描述“走路”不足以确定步幅、相位及逐帧关节坐标，固定动作也不对应唯一措辞。因此，统一模型学习的是两个方向的条件分布，而不是可精确求逆的确定性映射。

在这种多对多关系下，“共享”也有不同程度。共享潜空间只要求两个模态的表征可对齐；共享生成模型进一步要求同一骨干能够根据条件输出两种模态。TMR 的检索表征与 MotionGPT 的条件生成骨干分别对应这两种设计。前者可以给已有候选排序，后者还必须决定新的输出内容，所需接口并不相同。

2.4 输出边界与合法性

动作序列还需标识起止边界与缺失区域。MotionGPT 为此在码本范围之外加入结构符号：码本大小为 $K$ 时，编号 $K$ 与 $K+1$ 分别表示动作开始和结束，$K+2$ 表示缺失片段。这些符号控制序列结构，不参与动作码向量查询。

输出解析负责识别动作边界、移除控制符号，并将扩展词表 ID 转换为 $[0,K-1]$ 内的 codebook ID。边界缺失、空序列或越界编号均无法组成有效的动作潜表示。因此，词表分类与运动解码之间需要明确的结构协议。

3. MotionGPT 的 T5 计算链

3.1 编码器—解码器骨干

有了统一词表，就可以把动作任务组织成条件序列到目标序列的映射。MotionGPT 使用 T5 编码器—解码器结构：编码器读取条件序列，解码器在条件记忆上自回归预测目标。文本与动作共用扩展词表，输入端和输出端仍承担各自的计算职责。

T5 编码器可在有效条件位置之间进行双向注意力；解码器目标 self-attention 保持因果性，并通过 cross-attention 读取编码器结果。对于 M2T，整段动作词汇位于条件端；对于 T2M，文字指令位于条件端。两个任务共享词表与骨干，却拥有不同目标 token。

3.2 运动压缩器与条件张量

HumanML3D 配置的输入为 [B,T,263]。VQ 编码器先将张量转置为 [B,263,T]，通过两层步长为 2 的时序下采样与残差卷积，得到 [B,512,N]；当 $T$ 为 4 的倍数时，$N=T/4$。每个 512 维向量查询含 512 项的码本，输出整数张量 [B,N]。重建训练用码向量代替编码向量，再以两次上采样恢复 [B,T,263]，同时优化重建与 commitment loss。EMA 更新码向量，未充分使用的码可重新初始化。

压缩器训练完成后，动作编号包装为边界与动作符号，并与任务指令一起分词。若条件与目标的有效长度分别为 $L_I,L_O$，T5 的条件 Embedding 为 [B,L_I,d_LM]，编码器输出同形状的记忆；目标解码状态为 [B,L_O,d_LM]，词表头输出 [B,L_O,V_extended]。$d_{\mathrm{LM}}$ 由所选 T5 配置决定，$V_{\mathrm{extended}}$ 包含普通文字、512 个动作符号和三个结构符号。

条件端的 padding mask 限制有效记忆，目标端的 causal mask 限制文字或动作符号的生成前缀。两种模态经过同一词表头，但损失位置由任务目标决定；运动特征的 263 个连续维度不会直接成为 T5 的分类类别。

3.3 模板、损失与训练阶段

统一接口先确定符号协议，再定义监督位置。动作 codebook ID 经原子 motion token 映射进入扩展词表，Embedding 与输出分类层随词表同步扩展。任务模板则将文本、动作片段和长度条件组织为输入序列；它规定哪些变量已知、哪些变量需要预测，而非额外改变运动编码器的几何表示。

条件端的 attention mask 限制编码器记忆中的有效位置；目标端经过右移构成 teacher-forced 前缀，causal mask 阻止目标信息泄漏。目标 padding 使用忽略标签，不参与交叉熵。由此，条件可见性与损失可见性得到区分：一个已知动作 token 可以被 attention 读取，却无需在 M2T 中作为预测目标。

完整训练分为运动压缩器学习、运动—语言预训练和任务指令微调。第一阶段用重建监督确定运动词汇；第二阶段在固定词汇上学习运动与语言序列的关系；第三阶段把生成、描述、预测和补全组织成指令条件。统一语言模型的监督路径分别构造条件和目标，交叉熵作用在目标 token 上，动作编码器为它提供固定的编号接口。

3.4 模态条件与输出路径

T2M 以文字和任务指令形成编码器条件，解码器生成动作符号，再经词表逆映射与运动解码器恢复连续特征。M2T 以已有动作符号为条件，输出普通文本 token。两条路径共享参数，但动作重建损失与文字预测损失属于不同阶段，不能把文本交叉熵直接解释为对关节轨迹的几何监督。

M2T 的有效长度首先在运动端确定，经下采样转换为动作编号长度，再加上边界和指令位置；文本评价比较生成描述与语义标注。T2M 则还必须从编号序列恢复物理帧，检查几何、接触和时序连续性。共享骨干并未消除两种输出空间各自的有效性条件。

计算链中存在四种不同长度：原始帧数、有效 motion token 数、含边界符号的动作序列长度，以及完整语言模型输入长度。任务模板中的帧数约束作用于重建运动，动作切片使用 token 长度，语言模型截断则作用于最终输入序列；这三类操作需要遵循编码器的下采样比例和边界约定。

4.2 MG-MotionLLM 的粒度扩展

MG-MotionLLM 以统一框架处理粗粒度与细粒度的理解、生成。普通短描述监督整体动作；详细描述监督部位、阶段与局部变化；时间定位监督描述对应的运动片段。不同任务通过指令与数据格式进入模型，而不是把所有描述无区别地接到同一个训练字段。

运动 VQ 编码器提供固定离散接口，T5 根据任务指令区分普通描述、详细描述与生成目标。粒度变化主要改变条件和监督位置；如果压缩器未保留短暂局部事件，增加详细文本监督也无法恢复缺失的输入证据。

细粒度训练还改变正例的定义。如果动作中的一段抬手被局部描述单独标注，那么“整段动作—短描述”与“动作区间—细节描述”是不同监督对象。切片的帧边界与 token 边界需要换算，不能假定任何帧级边界都恰好落在编码器压缩块的边界上。

4.3 梯度竞争的合成算例

条件采样方差则表示同一文本下动作实现的多样性，并非重建误差。压缩失真比较同一输入及其重建，分布拟合误差比较学习分布与目标分布，数值采样误差比较近似求解与理想生成过程。足部接触、关节范围和非穿透还需相应几何约束，低潜空间误差不会自动保证这些条件。

运动 VAE 学习已有动作的潜表示与重建，条件生成模型则学习文本对应的潜变量分布。二者的误差来源不同：高质量重建说明数据流形附近的编解码较准确，而生成质量还取决于条件分布能否将采样限制在语义适合、解码稳定的区域。

5.2 文字与动作的输出头

表示连续以后，语言模型的输出接口也要相应改变。文字输出仍可写为词表上的 softmax，动作潜向量却不再对应一个有限类别。设统一骨干输出状态 $h$，文字头计算 $p(y\mid h)$；动作头计算连续分布 $p(z\mid h)$，后者可以通过扩散、流匹配或其他连续生成机制实现。共享上下文与分别建模输出，由此成为两个可以同时成立的设计。

连续向量构成序列位置时也可称为 motion token。此时 token 指计算单元，不要求对应整数类别；next-token prediction 可以分别由离散分类头或连续生成头实现。其概率模型取决于输出空间，而非 token 这一名称。

5.3 序列潜变量与整段潜变量

时序下采样得到的 $Z\in\mathbb R^{N\times d}$ 可以让每个潜位置对应一段时间范围；全局动作 VAE 也可以把整段动作压缩为少量潜变量槽位。两者拥有不同的时间结构。

全局潜变量汇聚整个片段的信息，序列潜变量则保留多个具有时序结构的位置。若编码器读取完整动作，任一潜位置都可能依赖未来帧。因此，潜序列长度与因果性是独立属性，流式生成需要进一步约束编码器的感受野。

6. MotionGPT3 的连续扩散路线

6.1 模态专属参数与共同注意力

连续 motion latent 与文本 Embedding 的统计结构不同。MoT（Mixture-of-Transformers）为不同模态配置专属变换，并通过共享 attention 建立信息交换。MotionGPT3 分别设置语言与运动的投影、归一化和前馈参数；模态标记选择对应参数，位置顺序与 attention mask 确定上下文的可见范围。

动作 VAE 把归一化特征 [B,T,263] 投影到 256 维，加入可学习分布位置，经九层 Transformer 编码得到均值与对数方差。latent_dim: [1,256] 表示每条动作采样一个全局潜变量，内部排列为 [1,B,256]。有效帧掩码排除 padding 位置；分布位置读取整段有效运动，因此这个潜变量概括整个片段。

在 GPT-2 small 配置中，运动理解头将全局潜变量映射为四个 768 维 holder，即 [B,4,768]，嵌入语言上下文。映射可写为 $H_m=\operatorname{reshape}(Wz+b,4,768)$：reshape 只把投影输出组织为四个位置，不增加原始潜变量的信息量。这些位置共同条件化语言计算，并非四帧或四段独立运动。与自然语言任务前缀相比，holder 保留模态位置，适配器负责连续高维条件投影；训练建立预测意义上的跨模态关联，而不保证运动流形与语言表征空间之间存在可逆同构。

图中的第一阶段只监督文本条件下的动作输出，冻结文字分支，使新运动分支学习读取已有语言特征；第二阶段继续冻结文字分支，加入动作描述与预测，实现双向对齐；第三阶段解除文字分支的冻结，通过指令联合微调。动作 VAE 在这三个语言—运动阶段保持固定，运动压缩与跨模态学习因而有明确分工。

6.2 占位状态与连续扩散头

生成动作时，条件文本后加入动作边界和四个运动输出占位。骨干一次计算这些位置，抽取 [B,4,768] 条件状态；扩散头结合它们与扩散步，对 [B,1,256] 的带噪全局潜变量去噪。基础扩散头包含三层、宽度 1024 的残差 MLP，以条件注意力和 AdaLN 调节噪声预测。它在 256 维潜空间中建模分布，不对每帧的 263 维特征执行词表分类。

M2T 交换接口方向：先编码已有运动，将潜变量投影到四个运动输入位置，然后由文字头逐词产生描述。动作潜变量在条件端可完整读取，文字输出保持前缀条件。此路径不需要采样新的动作潜变量，也不经过生成动作的扩散循环。

图中的 holder 为运动保留上下文位置，左侧适配器建立运动 latent 与语言宽度的映射。中间共享 self-attention 聚合跨模态信息，右侧则按输出空间分流：语言头估计离散概率，运动头将骨干状态作为扩散条件。参数共享和概率模型共享由此得到明确区分。

6.3 重建与生成结果的坐标恢复

VAE 解码首先产生标准化运动特征，反标准化再恢复各通道的物理尺度，根运动积分与局部关节变换由此恢复世界坐标。两个阶段的张量均可具有 [T,263] 形状，维度相同并不意味着单位相同；在标准化空间直接积分根位移，会把统计尺度误作物理位移。

重建将已有轨迹编码后的潜变量送回解码器，误差反映压缩所保留的几何信息。文本条件生成则采样新的潜变量，误差还涉及语义映射和潜空间分布的拟合；比较同一表示下的两类结果，能够区分压缩误差与条件生成误差。

7. 编码器因果性与流式条件

7.1 因果计算的三个环节

连续表示规定了输出空间，流式生成则进一步约束信息可见范围和输出时机。骨干的 causal mask 仅限制骨干位置间的信息流：若 $z_\ell$ 已经通过编码器聚合未来帧，后续掩码无法消除这些依赖。非因果 tokenizer 得到的序列仍可具有合法的自回归概率分解，但它的 token 前缀不一定对应可独立观测的物理帧前缀。严格在线地编码已发生的运动时，编码器也必须遵守物理时间的可见性约束；这与离线 token 序列能否进行自回归建模是两个问题。

解码器同样需要满足增量输出条件。若恢复当前片段依赖未来 latent，系统必须等待后续预测，从而产生额外缓存延迟。完整流式通路由因果压缩器、按 latent 顺序推进的骨干与增量解码器共同构成。

输出一个潜变量往往对应若干运动帧。系统即使满足因果性，也要先计算骨干状态、采样潜变量并解码片段，才能形成可执行帧。片段大小与采样开销决定第一次输出的等待时间，缓存与执行速度则共同影响后续响应。

7.2 未来帧扰动实验

8. LLaMo 的连续自回归与流匹配

8.1 因果连续运动单元

为了在连续空间中沿动作时间推进，LLaMo 使用因果 CNN 型连续 VAE，将运动组织成按时间顺序排列的潜向量。这样，骨干可以保留下一位置预测范式：文字位置通过离散词表解码，运动位置通过连续生成头采样下一个潜变量，再把该潜变量放回上下文。与预先设置全局运动槽位的方式相比，动作持续时间由逐步采样与停止预测共同决定。

运动输入采用 272 维表示，因果压缩器沿时间下采样四倍，得到 [B,N,32] 的连续潜变量，$N=T/4$。运动适配器将 32 维潜变量映射到语言模型宽度 $d_{\mathrm{LM}}$，文字查表得到同宽度 Embedding；两者按照 [BOS] 文字 [BOM] 运动 [EOM] 文字 [EOS] 的模态边界合并为 [B,L_total,d_LM]。

MoT 根据当前位置的模态选择 RMSNorm、Q/K/V 投影、注意力输出投影和前馈参数，再将各位置的 Q/K/V 放回共同顺序计算 self-attention。causal mask 阻止读取未来位置，padding mask 排除 padding 位置。文本相关参数保持冻结，运动分支学习跨模态适配。已有动作位于描述之前时，文字生成可读取全部运动输入；生成运动时，每个新潜变量只读取已有前缀。

8.3 停止预测与分阶段训练

外层自回归循环还需要学习运动终止条件。文本词表包含 EOS，连续 latent 则没有天然的结束类别。LLaMo 增设 exit head 预测运动是否结束，并与模态起止标记共同控制序列结构。

停止头过早触发会截断动作，过晚触发会引入重复或无关尾段。评价时需要检查语义完成度与生成长度，停止分类损失并不能单独表示动作已经完成。固定长度生成、由文本指定长度、模型自行停止，是三种不同的长度协议。

训练先对齐运动适配器与流匹配头，再更新运动相关骨干、适配器及生成头，最后只微调运动预测头与停止头。因果 VAE 和文字参数在跨模态学习中保持固定。联合阶段降低 M2T 样本比例，并为一个运动条件抽取四个流时间，缓解较快收敛的文字目标对运动生成的干扰。

连续自回归还会把采样误差带入后续前缀。为提高解码鲁棒性，压缩器在均值附近加入幅度受限的随机噪声；统一模型的 teacher forcing 输入也加入小幅潜变量扰动，使生成头不只适应精确的真值前缀。推理每次采样一个 32 维潜变量，追加到上下文并进行因果解码，直至停止头触发。外层序列延长与内层流积分因此共同构成完整生成过程。

这种风格条件同时约束躯干、上肢和步态的时间组织。序列 latent 需要保留局部姿态细节，自回归上下文则维持不同身体部位在后续片段中的一致性。图中呈现的是同一生成序列的多个时刻，可据此观察连续姿态的变化。

9. 两种输出接口的完整生成过程

9.1 离散动作的条件解码

T2M 的条件端由任务指令和文字组成，编码器输出供目标端读取的记忆；解码器逐个生成动作符号，直到动作结束标记。解析器移除边界符号，把词表 ID 转回码本 ID，动作解码器再将码向量恢复为连续特征。反标准化与关节恢复位于最后一步。

M2T 则先把已有运动编码为动作符号，把它们放到条件端，目标端逐词产生文字。此时，动作解码器不参与预测文本；运动的坐标恢复用于展示输入，与文字解码各自沿不同路径进行。两种任务共用骨干，输出路径由任务及模态边界选择。

9.2 连续动作的条件采样

连续路线先用动作 VAE 把运动压到潜空间。M2T 将已有潜变量投影成语言骨干可读取的运动输入；T2M 用骨干状态作为连续生成头的条件，从噪声采样潜变量，再交给动作 VAE 解码。文字端保持词表分类，动作端采用连续概率模型。

MotionGPT3 的全局潜变量接口在采样前给定目标帧长度，解码时一次恢复对应的整段动作。LLaMo 的因果潜变量接口则沿时间不断采样，下一个潜变量依赖已有前缀，停止头决定何时结束。这种长度协议差异直接影响编辑和交互：全局生成适合一次形成完整片段，增量生成可以在后续上下文中接收新条件，同时需要控制片段衔接与累积误差。

10. 联合评价与技术边界

10.1 分别评价压缩、理解与生成

动作压缩器可检查关节位置误差、旋转误差、时间平滑性和接触保持；T2M 可检查文字匹配、动作分布、多样性与几何质量；M2T 可检查参考文字相似性、部位、方向、次数、顺序及虚构细节。这些指标分别反映压缩、生成与理解能力，一个方向的提升并不能替代另一个方向的评价。

若模型扩展自预训练语言模型，还应评价纯文本能力。冻结文本分支有助于保留原有计算路径，联合更新则需要检查遗忘；多模态能力与基础语言能力之间的关系应由相同协议的测量说明。

不同动作表示、数据规模、骨干大小与评估器，会影响模型比较。HumanML3D 的 263 维与 LLaMo 使用的 272 维不是同一个输入空间；在恢复骨架后比较位置误差，可以统一一部分几何评价，而特征转换、帧率与根坐标约定仍会影响实际数值。

10.2 往返一致性与独立证据

文字 $Y$ 经 T2M 产生 $\hat X$，再经 M2T 得到 $\hat Y$，可以检查 $Y$ 与 $\hat Y$ 的一致性。若输出变成了“右手抬起”，而条件要求“左手抬起”，往返结果能够提示语义问题。

两个方向共享参数或训练数据时，也可能共享语义偏差。例如，生成器与描述器同时忽略左右部位，往返文本仍可能保持一致；描述器只概括整体行为时，局部异常也可能不进入输出。因此，往返一致性仅提供跨模态闭环的一致性度量。

独立语义评价需要直接从轨迹提取目标部位运动与事件顺序，并使用与训练监督独立的标注或评价器。物理质量则通过接触、穿透和动力学约束单独度量；跨模态一致性与运动可行性分别对应不同的评价目标。

10.3 连续生成的剩余难点

连续表示提供了保存精细变化的可能性，实际保真度仍取决于压缩率、损失度量与训练分布。某些微小 latent 误差会被解码器放大，长序列中的偏差又进入未来条件；过强平滑可能遗漏快速手势，高频噪声则可能表现为抖动。重建项、潜分布正则与生成头需要共同约束这种误差传播。

统一训练还面临目标尺度与收敛阶段的不一致。文字损失较快下降并不单独决定其是否主导共享参数，实际贡献由梯度范数、方向和采样权重共同决定。LLaMo 通过分阶段训练和任务比例调整处理这种耦合；模态专属参数减少部分直接竞争，也相应增加参数与训练成本。

交互应用进一步引入随时间变化的状态与约束。用户临时修改指令时，系统要将新要求与已生成的动作前缀协调；人与人、物体或地面的接触需要保留接触位置和时机，机器人执行还要满足关节与动力学限制。接下来的人—人、人—物与场景任务，将把伙伴、物体和环境状态作为条件，与运动生成共同建模。
