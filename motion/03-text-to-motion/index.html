03 文本驱动的单人动作生成

发表于2026-10-03|更新于2026-10-05|「Motion」3D人体动作生成3D 人体动作建模
|浏览量:

文本驱动的动作生成（text-to-motion，T2M）以自然语言为条件，产生随时间变化的三维人体运动。文本提供动作类别、时序关系和局部属性等语义条件，生成模型据此估计尚未确定的空间与时间自由度。例如，“一个人向前走，随后转身并抬起右手”给出了动作类别、顺序和身体部位，却没有确定步幅、转身半径、行走速度、手腕的精确位置，也没有规定每个动作持续多少秒。这些未确定变量对应多种满足语义与运动学约束的解，因此 T2M 需要建模条件分布，而非建立文本到单一轨迹的确定性映射。

三维动作的输出还具有几何约束。右手抬起时，肩、肘和腕共同改变；行走时，身体平移、足部接触和腿部摆动不能各自独立生成。动作特征通过反标准化、根轨迹恢复、前向运动学与网格驱动映射为可见几何。概率模型规定输出分布，运动表示规定变量的含义，几何恢复则确定这些变量对人体姿态的实际作用。三者共同决定生成结果。

1. 文本条件、动作长度与多解性

这一分解区分了长度分布与给定长度的运动分布；实现中可以使用独立模块，也可以通过同一生成器联合建模。有的接口要求用户指定帧数；有的先预测长度；有的逐步产生动作 token 并预测结束标记。输入“跑两步”时，模型还需区分动作次数与输出长度：把序列截成两秒不能保证恰好两步。

帧率决定时间含义。按每帧占据一个播放周期计，20 fps 下80帧的播放时长为4秒，30 fps 下为约2.67秒；首末采样时刻之差则为 $(T-1)\Delta t$。训练长度约束、生成帧数与播放帧率分别决定可生成的范围、序列大小和实际时长。为构造批量张量，短序列通常 padding 到 $T_{\max}$，有效帧掩码为

本章区分三种索引：$t$ 表示 $T$ 个物理帧中的位置；$\ell\in\{0,\ldots,K-1\}$ 表示 $K$ 个压缩片段或 motion token 中的位置；$k\in\{0,\ldots,N_d\}$ 表示离散扩散噪声级。连续生成时间使用 $s\in[0,1]$，它参数化噪声路径，并不具有秒的单位。若时间压缩倍率为 $u$，一个 token 通常对应约 $u\Delta t$ 的运动区间，而一次去噪更新不会使人物在物理时间上前进一帧。

有效帧掩码首先限制重建损失与评价统计；采用注意力 padding mask 的网络，还需屏蔽无效键值。两种掩码的作用不同：前者规定哪些输出接受监督，后者规定网络可以读取哪些位置。生成结束后的无效帧不参与骨长、速度和文本匹配统计。

数据进入网络前还要统一坐标和尺度。以 HumanML3D 的263维表示为例，预处理先确定地面与初始朝向，再计算根运动、根相对关节位置、6D 旋转、关节速度和足部接触，最后用训练集均值与标准差逐维标准化。若一条描述只对应原运动的某个时间区间，动作裁剪与文字配对必须使用同一区间。批量输入由此成为 [B,T,263]，同时保留 [B] 的有效长度；反标准化与根轨迹恢复则构成输出端的逆过程。

多样性也有两种口径。不同描述产生不同动作，反映整体分布的覆盖；同一描述重复采样得到多个正确动作，反映条件分布内部的多解性。条件多样性的评价以语义一致性为前提；偏离描述的样本扩展了输出分布，却未提高目标条件下的覆盖率。

2. 动作片段与层次化变分生成

建立条件分布的一种早期思路，是先预测长度，再逐段组织运动。直接逐帧生成时，每一步都要决定大量关节特征；motion snippet code 将相邻数帧的局部动态压缩为潜变量，降低时序生成器每一步需要预测的维度。该编码由重建目标学习，不预设固定动作类别；其表示能力取决于时间感受野、潜空间容量和训练动作的分布。

在这种组织中，Text2Length 与 Text2Motion 分别承担长度预测和内容生成。前者根据文本估计长度的离散分布，后者在选定长度下生成运动片段，再由运动解码器恢复逐帧特征。长度通常以片段单位处理，最终再转换到动画帧。两种模块使用配对动作与文字学习；HumanML3D 的原始配对包含14,616段运动和44,970条描述，一段运动可以对应多条表述，描述也可能只覆盖其中一个时间区间。

重建项约束逐帧失真，稀疏项限制编码幅度，平滑项约束潜变量的时间差分。最后一项定义的是潜空间中的正则性，并不等价于关节加速度或接触力连续；解码器的非线性雅可比会改变潜空间距离对应的几何变化。过大的平滑权重因此可能同时削弱高频姿态细节与真实接触切换。完成这一步后，片段编码器提供固定的潜变量目标，运动解码器则继续随时序生成网络微调，使预测片段能够重建为逐帧动作。

文本由 word embedding 与词性编码共同表示。每个词的 GloVe 向量为300维，词性向量经线性映射后与 word embedding 相加，再送入双向 GRU。逐词输出 [B,L,2H_t] 为片段生成提供注意力键值，句子表示 [B,2H_t] 初始化时序生成状态。Text2Length 使用双向 GRU 和分类头，预测片段数量的类别分布，并用真实长度类别的交叉熵训练。

长度确定后，同一文字仍有多种合理动作。变分生成用随机潜变量 $v$ 表达这种变化：条件生成模型 $p_\theta(X\mid v,c)$ 提供重建，识别模型 $q_\phi(v\mid X,c)$ 在训练时读取真实动作。其基本目标是最大化条件变分下界

时序变分模型进一步对片段位置 $\ell$ 建立条件先验和识别分布。先验 GRU 读取上一片段、文本注意力上下文及剩余长度，输出高斯参数 $(\mu_\ell^p,\sigma_\ell^p)$；识别 GRU 额外读取当前真实片段，输出 $(\mu_\ell^q,\sigma_\ell^q)$。训练从识别分布采样，运动解码 GRU 根据随机变量、前一片段和文本上下文预测下一片段。损失同时比较预测片段与真实片段、解码动作与真实动作，并累加各位置的 KL 散度：

$z_\ell$ 是运动片段编码，$v_\ell$ 是表达多解性的随机变量，二者承担不同功能。推理先采样长度，再仅从先验分布取得 $v_\ell$，逐段生成 $\hat z_\ell$，最后统一送入运动解码器。训练使用真实历史而推理使用生成历史，会形成 exposure bias；将预测片段纳入训练前缀，可减小历史输入的分布偏移。

片段压缩决定局部运动的可恢复程度，条件生成决定文字如何选择片段分布。压缩中丢失的手部细节会延续到生成结果，片段预测偏差则可能在衔接处造成速度突变。帧级重建与片段级监督分别作用于这两个环节。

几何监督需作用于具有明确坐标与单位的量。直接关节表示允许计算位置和足部速度误差；对于 HumanML3D 复合特征，标准化空间的重建损失与恢复后关节空间的几何损失分别约束特征一致性和空间关系。接触监督进一步利用有效接触时段选择受约束位置。

高斯噪声作用于表示所在的欧氏空间，不保持 $R_j^\top R_j=I$、$\det R_j=1$ 或固定骨长等约束。因此含噪状态是推断过程的辅助变量，无需在每个噪声级解释为有效人体姿态；最终解码才把预测变量映射到几何对象。若骨长或旋转约束没有由解码结构严格保证，有限权重的几何损失仍只能约束平均残差，不能把学习到的分布直接等同于物理可行集合。

前向加噪数值算例以正弦信号构造单坐标轨迹，将高维运动的仿射加噪关系约化为一维。已知噪声时，逆运算是仿射可逆的；学习问题的困难在于推理时未知原始信号与所加噪声，必须从条件分布估计二者。

4. 条件注入、classifier-free guidance 与张量实现

去噪目标通过条件网络实现。文本、扩散步与运动帧分别编码后，需要在兼容的隐藏维度中融合。MDM 的核心输入接口是 [B,J,F,T]。其中 $J$ 和 $F$ 的具体含义取决于动作表示：对复合向量配置，它们不一定对应真实关节数与每关节特征数。输入处理将二者合并，转换为 [T,B,J×F]，再线性投影到 Transformer 隐藏维度。

在 HumanML3D 配置中，输入是 [B,263,1,T]。展平与转置后得到 [T,B,263]，线性层逐帧投影为 [T,B,H]。冻结 CLIP 产生 [B,512] 的句子向量，经投影映射到 $H$ 维；扩散步通过正弦编码与多层感知机得到 [1,B,H] 的 embedding。二者相加构成一个条件 token，放在运动序列前：

5. 连续潜空间扩散与重建瓶颈

5.1 运动压缩与潜空间采样

帧空间扩散在每个去噪步骤都处理完整运动特征，长序列会增加重复计算。潜空间扩散先用压缩器保存主要运动信息，再在较紧凑的表示上学习条件分布。MLD 先训练运动 VAE，将整段动作压缩为连续潜变量 $z$，再训练条件扩散模型生成 $z$。推理计算链为

运动编码器将 [B,T,D] 投影为时序隐藏特征，加入用于聚合的可学习查询 token，并屏蔽 padding 帧，输出潜分布的均值与方差。重参数化 $z=\mu+\sigma\odot\epsilon$ 得到连续潜变量。下文采用 batch-first 记法 [B,K_z,d_z]；官方运动编码器返回的顺序是 [K_z,B,d_z]，进入去噪器前再交换轴。$K_z$ 是 latent token 数量，不必等于帧数。解码器读取这些潜变量，以所需长度的帧查询恢复 [B,T,D]，并在有效帧上计算重建损失。

VAE 固定后，文本编码与扩散步共同进入潜空间去噪器。训练对真实动作编码得到的 $z$ 加噪，学习噪声预测；推理从同形状高斯噪声出发，逐步生成 $\hat z$，最终只调用一次运动解码器。动作长度由解码查询与掩码决定，而潜变量索引与动画帧索引具有不同含义。

训练阶段有明确分工。VAE 目标平衡动作重建与先验约束；条件扩散目标在已经建立的潜空间中学习文本到潜变量的分布。过强的压缩会丢失短促接触、手部细节或高频变化；过弱的潜空间约束又可能使生成分布难以覆盖真实编码。潜空间容量因而需要在压缩效率与重建保真度之间平衡。

该局部上界区分既有编码—解码对的重建误差与潜空间生成误差。增大采样步数只能改进潜变量分布及其数值近似，无法直接补回固定解码器表示集合之外的细节；接触附近较大的解码雅可比还可能放大很小的潜变量偏差。

整段压缩通常读取未来帧，因此它与在线因果解码不是同一接口。整段解码后的逐帧播放仍依赖完整生成结果，无法在解码过程中依据新指令更新尚未生成的后续运动。

5.2 潜空间一致性与少步生成

压缩减少了每一步需要处理的数据，反复去噪的次数仍然影响响应时间。潜空间一致性蒸馏进一步学习一个映射：沿同一条去噪轨迹取得的不同噪声状态，应当预测到相同的 clean latent。MotionLCM 利用预训练扩散教师提供轨迹上的相邻状态，让在线网络与目标网络的预测保持一致；目标网络通过在线网络参数的指数移动平均更新。若以 $s$ 参数化概率流 ODE 的连续噪声轨迹，理想一致性映射满足 $f_\theta(z(s_1),s_1,c)=f_\theta(z(s_2),s_2,c)$，其中两个状态属于同一教师轨迹，$s_1,s_2$ 不对应不同的动作帧。学生网络由此以一步或少量调用近似教师的端点映射，再由运动解码器恢复动作。蒸馏精度受教师分布、轨迹离散误差和学生函数容量共同限制，减少调用次数不会自动保留所有稀有运动模式。

图中左侧通过同一去噪轨迹上的预测一致性减少采样迭代；右侧则引入 Motion ControlNet 与轨迹编码器，将指定关节的空间条件送入潜变量生成，并在解码后的关节上计算控制损失。这两种改进针对不同问题：减少步骤提高响应速度，增加轨迹条件规定位置。“转弯”限定运动语义，转弯位置与半径则由几何条件确定；两类条件在模型中承担互补作用。

6. 离散运动 token 与时间自回归

紧凑表示也可以由连续向量改为离散编号。motion token是编码器输出经量化后得到的基本单元，生成器由此可以采用词表分类。T2M-GPT 将 VQ-VAE 与条件自回归模型连接：编码器把 $T$ 帧动作下采样为 $K$ 个潜向量，每个潜向量映射到码本最近邻，得到整数序列 $q_{0:K-1}$；解码器再用码向量恢复运动。token 的时间单位是压缩片段，不是单个关节，也未必是一帧。

生成器建模

式中 $q_K=q_{\mathrm{end}}$，有效运动 token 的索引范围仍为 $0\leq\ell<K$。文本特征构成条件输入；运动 token 经 embedding lookup 并加入位置编码后进入因果 Transformer。训练使用真实前缀并并行计算各位置的交叉熵，推理则逐个采样 token，直到结束标记或长度上限。目标序列右移与 causal mask 共同隔离当前预测位置及其未来目标，保证训练所用条件与自回归分解一致。

量化训练还涉及 codebook 的利用率。EMA 更新、失活码重置等机制帮助码向量覆盖编码分布；仅增加码本大小可能导致很多编号从未使用。生成器输入中加入一定比例的扰动 token，可以缓解真实前缀与生成前缀的差异，但不能完全消除长动作中的误差累积。

量化算子的梯度处理决定编码器的训练方式。设编码向量为 $z_\ell$，码本为 $\{e_v\}_{v=1}^V$，编号为 $q_\ell=\arg\min_v\|z_\ell-e_v\|_2^2$。最近邻选择在量化分区内部保持不变，在分区边界发生离散跳变，因而无法直接为编码器提供有效梯度。straight-through estimator 在前向使用 $e_{q_\ell}$，反向以近似恒等映射将重建梯度传给编码器。常见 commitment loss $\|z_\ell-\operatorname{sg}(e_{q_\ell})\|^2$限制编码结果偏离选中码过远，码本项或 EMA 负责移动码向量。stop-gradient 分别控制编码器与码向量的更新路径，使重建梯度和量化约束作用于对应参数。

token 长度与帧长度同样不能混用。若编码器时间下采样倍数为 $u$，$K$个有效 token 大致对应 $uK$帧；边界补齐和卷积规则会影响精确对应。结束符是分类目标的一部分，padding 只是批处理占位；损失应包含有效结束符并排除 padding。过早生成结束符会截断动作，生成上限被触发则可能留下未完成的语义。

自回归训练优化真实历史下的条件风险，推理却在模型生成的历史分布下继续采样，这一分布偏移构成 exposure bias。为了刻画传播机制，可在连续隐藏状态中考虑同一随机输入耦合下的局部扰动。记对应两条隐藏状态轨迹的距离为 $e_\ell$。若状态更新对历史扰动的放大系数不超过 $L$，单步近似误差不超过 $\varepsilon$，则

$L<1$ 时该上界有界，$L=1$ 时误差可线性累积，$L>1$ 时上界允许几何放大。这里的界适用于满足局部稳定性假设的隐藏状态映射，不能直接跨越离散 argmax 或量化分区边界。实际采样还可能切换到另一条合理轨迹，因此相对单条真值的偏差并不全部属于生成错误。

整段扩散通过联合更新所有帧，绕开了上述逐 token 固定前缀的传播方式，但将误差传播转移到噪声轴；它仍可能产生根漂移、足部滑动及长时段语义失配。离散化失真、条件建模偏差与序列传播应分别评价，不能把扩散的联合更新解释为全局一致性的保证。

固定码本的残差量化算例把高维量化几何约化到一维。每层选择一个码向量，累计重建位于多个有限集合的 Minkowski 和中；增加残差层允许在更多码向量的和集中选择重建；若额外码本包含零，可表示集合不会缩小，但不含零时没有这一包含关系。算例的码本包含零，因此最近邻选择至少可以保持上一层误差不增。

8. MotionMillion 的数据扩展与组合泛化

上述生成器都从配对数据中学习文字与运动的关系，能够覆盖的行为也受数据限制。扩展数据时，可以统一已有动作库，也可以从网页视频估计三维人体运动。MotionMillion 包含超过200万条序列和2,000小时数据，扩大了语义和动作覆盖。视频估计的运动属于伪真值，遮挡、镜头运动与姿态重建偏差使其误差分布区别于高精度动捕。

视频处理链需要处理镜头切换、人体检测、静止或抖动片段筛选、SMPL 运动估计及后续过滤。文本标注由视觉语言模型生成描述并经过质量筛选。各处理阶段具有不同的误差来源：遮挡导致手臂估计偏离，摄像机运动影响根轨迹，文本描述遗漏动作阶段。这些偏差随动作进入训练集，可能在生成中表现为同类关节偏移或根路径失真；系统性重建误差会随数据扩展进入生成模型的学习目标。

大规模数据还要求编码稳定。MotionMillion 使用根空间中的线速度、以6D旋转编码表示的相邻帧朝向增量，以及局部位置、速度与旋转。该6D增量属于旋转的嵌入表示，并非李代数中具有弧度每秒单位的三维角速度；位置与旋转则来自同一骨架。运动先经过小波变换，再输入编码器；解码器输出经过逆小波变换恢复连续序列。小波将不同变化频率分开组织，有助于编码器保存快速变化，减轻离散压缩后的抖动。

各维编号可以按混合进制合成一个整数 token。FSQ 的词表由固定网格构成，不需要搜索可学习的最近邻 codebook；编码器仍需通过重建目标学习运动特征到量化网格的映射。固定网格避免了码向量更新中的失活问题，但并不保证训练数据均匀占据所有网格单元；实际编码熵与名义容量 $\log_2 V$ 仍可能相差很大。量化前后的连续映射与运动解码器由重建损失联合训练，得到 [B,K] 的整数运动序列。

生成器将 T5-XL 的逐词特征与 motion token embedding 投影到同一隐藏维度。若文本有 $L_c$ 个位置、运动有 $K$ 个位置，输入为 [B,L_c+K,H]。混合注意力让文字位置之间双向读取，而运动位置读取全文与已有运动前缀；文本位置不读取运动后缀，防止间接泄漏未来目标。每个 Hybrid Attention Block 包含 RMSNorm、混合注意力和前馈网络，分类头输出运动词表 logits，以运动目标的交叉熵训练。

训练先建立运动编码，再用固定编码产生运动 token 训练生成器。推理编码全文，逐个采样运动 token，随后经过 FSQ 逆映射、运动解码与逆小波变换恢复帧序列。扩大到3B、7B 等参数规模增加了建模容量，其组合泛化能力还受训练数据覆盖与评价分布影响。固定划分内的泛化和域外文本条件下的零样本生成分别对应不同问题。即使样本总量增加，条件空间中的长尾组合仍可能稀疏：若某种组合在采样分布中概率为 $p_c$，$n$ 次独立采样全部遗漏它的概率为 $(1-p_c)^n$。模型规模无法单独改变这一覆盖事实；视频估计引入的系统偏差也不会仅因样本增多而消失。

左侧动作包含旋转、腾空和踢腿，右侧按抬臂、迈步挥砍与低位收势组织连续姿态。这类描述将多个局部条件组合为完整动作，因此对生成器的要求超出了单一动作类别识别。

组合泛化包含多个相互独立的动作属性。例如“左脚迈出两步，右手一直保持肩高，最后逆时针转身”包含左右、次数、持续约束和顺序。整体语义相似度对各属性的敏感程度不同，因而需要分别评价部位、数量、持续时间和顺序。MotionMillion-Eval 将域外描述与复杂组合条件纳入评价，用于考察常规短动作配对之外的语义覆盖。

9. 因果潜空间与连续流式生成

整段生成适合提前给定文字的短片段，但交互应用可能在运动过程中收到新指令。流式生成因此要求模型依据已有历史持续输出，并让新条件影响后续运动。MotionStreamer 接收持续到来的多轮文本，逐步生成可以在线解码的动作潜变量：因果时间自编码器保证当前潜变量对应的帧不依赖未来潜变量；自回归网络读取历史潜变量和当前文本，生成条件特征；扩散头据此采样下一个连续潜变量。

因果压缩要求编码器与解码器都不读取未来。MotionStreamer 将运动重采样到60 fps，使用272维根空间表示，以因果一维卷积将 [B,T,272] 压缩为 [B,T/4,16] 的连续潜变量序列。卷积在时间轴左侧 padding；潜变量的均值与方差由编码器预测，重参数化后接受重建、KL 与根关节重建监督。对根运动额外加权，可以减轻误差累计对后续全身位置的影响。

扩散头将16维加噪潜变量线性投影到内部宽度，扩散步经正余弦 embedding 和 MLP，条件特征 $h_\ell$ 经另一线性映射；后两项相加形成调制向量。每个残差 MLP 块由它产生归一化的位移、缩放和残差门，输出层再投影回16维噪声预测。训练可并行处理多个时间位置，采样时则只为下一个潜变量执行这条小型去噪链。

因此，Transformer 负责长程上下文，扩散头负责当前连续潜变量的多解分布。若直接用均方差回归下一个潜变量，多峰条件分布的均值可能落在低概率区域，产生幅度减弱或姿态模糊的输出；条件扩散保留了在同一历史下采样不同后续运动的能力。生成一个潜变量后，因果解码器即可产生对应帧，无需等待整段完成。

该架构包含两个嵌套生成过程：外层 $\ell$ 推进运动片段，内层 $k$ 在固定 $\ell$ 上采样该片段的连续潜变量；解码出的物理帧再由 $t$ 索引。局部 diffusion head 并不使整个系统成为整段扩散，因果前缀的误差传播仍由外层自回归结构决定。

连续潜变量避免了离散 codebook 量化，但压缩与前缀误差仍存在。Two-Forward 训练首先用真实前缀计算预测，再按逐渐变化的比例用预测潜变量替换部分真实输入，第二次前向在混合前缀上接受监督。Mixed 训练同时使用 HumanML3D 的独立文字动作对与 BABEL 的相邻动作区间：前者没有历史运动，后者带有前一段上下文，网络由此学习新条件与已有姿态之间的衔接。

连续序列也需要停止依据。模型把全零的“不可能姿态”送入因果编码器，建立参考结束潜变量，并将它作为训练序列的末端目标。推理时，当前潜变量与参考结束潜变量的距离小于阈值，当前指令便结束；下一指令替换文本条件，将刚生成的动作作为历史继续采样。停止条件由连续潜空间中的距离判定实现。

流式能力同时受生成、解码与缓冲策略影响。首帧延迟衡量开始输出需要多久，指令切换延迟衡量新条件何时影响运动。已经输出的帧无法由新指令改写，预先缓存的运动又可能推迟响应；缓存长度因而需要在稳定播放与及时控制之间取舍。指令衔接处的根速度和关节加速度刻画转场连续性；因果性规定读取范围，连续性还取决于历史条件与训练目标。

关节到人体表面的拟合还会引入几何误差。关节序列描述位置与速度，人体表面进一步呈现脚底接触、穿透和轮廓。关节位置仅对人体表面施加稀疏几何约束，关节到曲面的映射存在未观测自由度；因此关节轨迹接近并不保证脚底与地面的间距、法向或穿透量同样接近。

10.2 评价指标与误差来源

不同路线最终都输出运动，误差却可能出现在不同层次。编码—解码重建衡量表示能保存的细节；条件生成衡量文字与潜变量或 token 的对应；关节恢复和表面拟合决定这些变量怎样呈现为几何。末端位置偏差可能来自前面的旋转误差，脚底穿透也可能来自最后的拟合，两者在渲染中都表现为姿态异常。

R-Precision 衡量正确文本在候选集合中的检索排名，matching distance 衡量动作与配对文字的特征距离。二者由评估编码器的语义空间决定，方向、次数或短暂状态若未被编码充分区分，也会被分数弱化。FID 比较真实与生成动作的特征分布；Diversity 描述跨条件样本间的变化，Multimodality 描述同一条件内的变化。它们分别观察配对、分布和多解性。评估映射 $E$ 通常不可逆，因而 $E(X_1)\approx E(X_2)$ 并不推出 $X_1\approx X_2$；被编码器压缩的短时接触或局部方向错误可能同时被多种特征空间指标忽略。

指标值还受到表示与评价空间影响。263维与272维表示配套的评价模型可能不同，同名 FID 因而未必处于同一特征空间。动作长度、引导强度和条件采样分布改变生成集合，也会改变检索、分布及多样性统计。

几何指标直接作用于坐标或旋转。接触时的足部速度刻画滑步，脚底最低点与地面的距离刻画悬空或穿透，骨长变化刻画骨架一致性，速度与加速度刻画时间变化。过度平滑会降低加速度，也可能抹去跳跃着地的真实冲击；这些运动学量描述几何与时序，动力学可执行性还涉及质量、惯量、接触力和执行器。
