02 概率论与数理统计

发表于2026-09-29|更新于2026-10-07|「CV」看得见的计算机视觉从神经网络到 Transformer
|浏览量:

上一章的网络输出的是一组实数分数。然而，要把这些分数用于分类或文本生成，还需要回答三个问题：第一，分数如何转换为概率？第二，一整段序列的概率应该如何计算？第三，怎样衡量预测分布与真实数据之间的差距，从而得到一个可以优化的损失函数？

对应这三个问题，Softmax 将分类分数转换为归一化的分布，概率的 chain rule（链式法则）把序列概率分解为逐位置条件概率，cross entropy（交叉熵）则提供可优化的预测损失。它们分别规定 Transformer 的词表输出、序列建模方式与训练目标。本章还介绍期望和方差，为后续注意力中 $\sqrt{d_k}$ 缩放因子的推导作准备。

1. 联合概率与条件概率

1.1 定义

先以垃圾邮件分类为例，说明联合概率与条件概率。设一个邮箱中共有 100 封邮件，其统计情况如下：

  • 30 封是垃圾邮件，70 封是正常邮件；
  • 25 封包含关键词“中奖”；
  • 在这 25 封邮件中，20 封是垃圾邮件。

现在从中等概率地抽取一封邮件。设事件 $A$ 为“是垃圾邮件”，事件 $B$ 为“邮件包含关键词‘中奖’”，则有：

其中，$P(A,B)$ 表示“邮件是垃圾邮件”和“关键词包含‘中奖’”两个事件同时发生的概率。数学上将这类概率称为联合概率 (joint probability)。如果已知邮件包含关键词“中奖”，那么抽取范围就缩小到了这 25 封邮件，其中垃圾邮件的比例为 $20/25=0.8$，这就是条件概率 (conditional probability)：

等价地，上式也可以写作 $P(A,B)=P(A\mid B)P(B)$。

用方格表示这 100 封邮件，可以更直观地看到条件概率的含义：给定条件 $B$，相当于把统计范围从全部邮件缩小到含有关键词的那一部分，再在这一部分中重新计算比例。

1.2 条件方向与贝叶斯公式

需要注意的是，条件的方向不能互换。例如，已知是垃圾邮件时，包含“中奖”的比例为 $P(B\mid A)=20/30\approx0.667$，这与 $P(A\mid B)=0.8$ 并不相同，原因在于两者的统计范围分别是 30 封和 25 封邮件。两者之间的换算关系由贝叶斯公式 (Bayes’ theorem) 给出：

朴素贝叶斯分类器 (Naive Bayes Classifier) 正是利用这一公式，从“各类别中出现某个词的频率”推出“出现某个词时属于各类别的概率”。此外，条件概率描述的只是统计上的关联，本身并不表示因果关系。

1.3 模型中的条件分布

回到神经网络。在分类任务中，输入记为 $x$，类别记为 $y$，模型给出的预测分布写作 $p_\theta(y\mid x)$，其中 $\theta$ 表示模型参数。对于每个输入，模型都会在同一个候选类别集合上分配概率；而训练的目标，就是使这种条件分布与数据中的输入—标签关系相符。

2. 序列概率与链式法则

2.1 链式分解

在理解了条件概率之后，就可以讨论序列的概率。文本本质上是一个 token 序列。设三个位置的随机变量为 $Y_1,Y_2,Y_3$，它们的取值为 $y_1,y_2,y_3$。反复应用条件概率的定义，联合概率可以分解为：

这就是链式法则 (chain rule)。值得强调的是，它是一个恒等式，并不需要假设各位置相互独立：每个因子都可以依赖于前面的全部取值。反过来，如果直接把联合概率写成 $p(y_1)p(y_2)p(y_3)$，才是额外引入了独立性假设。独立性假设与词袋表示需要区分：前者限制随机变量之间的依赖，后者只记录 token 的出现情况，因此不保留次序。

下面以序列“猫／在／睡觉”为例，设模型给出：

那么，这三个 token 构成的前缀概率为 $0.4\times0.7\times0.5=0.14$。在这里，每个数都来自对应位置上的一个完整分布。例如，第二步的 0.7 表示“前缀为‘猫’时，下一个 token 为‘在’”的概率，其余候选则共同占据剩下的 0.3。因此，如果换一种排列方式，每一步的条件都会随之改变，不能通过简单交换这三个数来得到新序列的概率。

如果把每一步的候选都画出来，链式分解就对应于一棵概率树：从根节点出发，每经过一条边就乘上一个条件概率，而一条完整路径的概率就是沿途各边概率的乘积。

3.2 平移不变性与数值稳定

Softmax 有一个重要的性质：它只依赖于分数之间的差。具体而言，如果给所有分量都加上同一个常数 $c$，那么公共因子 $\exp(c)$ 会在分子和分母中相互抵消：

利用这一性质，实现中通常取 $c=-\max_jz_j$，使最大的指数输入为零，从而避免 exp 溢出。与平移不同，如果把所有分数都乘以一个大于 1 的数，就会放大分数之间的差距，使分布更加集中于最高分项，但类别的排名保持不变。后续第 05 章的采样温度与第 07 章的 $\sqrt{d_k}$ 缩放，都利用了这一性质。

例如，取四个候选的 logits 为 $[2,1,0,-1]$，计算 $\operatorname{softmax}(z/\tau)$，可以比较缩放的效果：除以一个小于 1 的数会放大差距，分布变得更尖锐；除以一个大于 1 的数则会缩小差距，分布变得更平坦。

3.3 归一化集合

此外，Softmax 的含义还取决于它在什么集合上进行归一化。在语言模型的输出层中，它在词表的所有 token 之间分配下一个 token 的概率；而在注意力中，它在可访问的序列位置之间分配加权系数。两者使用的是同一个运算，但表达的是不同的分布。

还需要注意的是，softmax 只保证输出具有概率分布的形式。例如，模型给某一类别 0.9 的概率，并不意味着这类预测在现实中有 90% 的正确率。预测概率与实际频率是否一致（称为校准 (calibration)），需要用数据另行检验。

5.1 似然函数

有了概率模型之后，接下来的问题是如何选择参数。设训练集包含 $N$ 个输入—标签对 $(x^{(n)},y^{(n)})$，并假设在给定输入的条件下，各样本的标签相互独立。那么，模型赋予这组观测标签的联合概率为：

5.2 负对数似然

然而，直接连乘大量小于 1 的概率，会造成数值下溢。由于对数是严格递增函数，最大化 $L(\theta)$ 等价于最大化 $\log L(\theta)$。在此基础上取负号，并按样本数取平均，就得到了可以最小化的负对数似然 (Negative Log-Likelihood, NLL) 损失：

其中，$r_n$ 是模型为第 $n$ 个样本的观测标签分配的条件概率。仍以 logits $[-1.4,1.4]$ 为例：若标签是第二类，单样本损失为 $-\log0.9427\approx0.0590$；若标签是第一类，损失则为 $-\log0.0573\approx2.8590$。也就是说，模型给观测标签分配的概率越低，损失就越大；当这个概率趋于 0 时，损失趋于无穷。

负对数函数的形状决定了这种惩罚是不对称的：当概率接近 1 时，损失的变化很平缓；而当概率接近 0 时，损失会急剧增大。下图标出了上面两种情况在曲线上的位置。

进一步地，对序列使用链式分解之后，负对数乘积就变成了逐位置负对数概率之和。以“猫／在／睡觉”为例，总损失为 $-\log0.14\approx1.9661$，按三个位置取平均则为 0.6554。需要注意的是，当序列长度不同时，“按所有 token 平均”与“先按句子平均、再对句子平均”会赋予长句不同的权重；此外，填充位置是否计入损失，也会改变最终结果（第 03、05 章）。

最后，最大似然只优化训练集上的目标。模型在新数据上的表现属于泛化问题，需要在未参与训练的数据上进行评价（第 04 章）。

6.3 困惑度

在语言建模任务中，研究者通常用困惑度 (perplexity, PPL) 来报告模型效果。它是每个 token 平均负对数似然的指数：

沿用第 5.3 节“猫／在／睡觉”的序列算例，平均损失为 0.6554，对应的困惑度约为 $e^{0.6554}\approx1.93$。直观上，困惑度相当于模型在每一步“平均在多少个等可能的候选之间犹豫”：如果均匀地从 $K$ 个 token 中猜测，困惑度恰好为 $K$。需要注意的是，不同分词方式下的 token 数量不同，因此困惑度不能直接跨词表进行比较。

08 多头注意力与位置编码
