08 多头注意力与位置编码

发表于2026-09-29|更新于2026-10-07|「CV」看得见的计算机视觉从神经网络到 Transformer
|浏览量:

上一章介绍的单头注意力存在两个局限。第一，一个 head 为每个 Query 只产生一组权重，所有 Value 特征都按这组权重聚合。若不同特征需要读取不同位置，单一加权分布就需要在这些关系之间折中。例如，一个动词的表示可能需要同时整合主语、宾语和时间状语。第二，注意力的计算只依赖于向量的内容，而与位置无关；在不包含位置信息和顺序掩码时，重排输入只会同样重排输出，不能为相同内容赋予不同的顺序语义（第 3 节）。

针对这两个问题，Transformer 分别引入了 multi-head attention（多头注意力） 与 positional encoding（位置编码）。其中，multi-head attention 的思路与卷积网络相通：卷积层使用多个卷积核，并行地提取边缘、纹理等不同特征，再在通道维度上合并；类似地，multi-head attention 使用多组投影，并行地计算不同的注意力分布，再在特征维度上合并。而 positional encoding 则是把位置信息显式地注入输入或注意力分数之中。

1. multi-head attention

1.1 投影、分头与拼接

1.2 参数量与高效实现

在原始的基础模型中，$d=512$、$H=8$、$d_k=d_v=d/H=64$，因此拼接之后恰好是 512 维。如果忽略偏置，Q/K/V 投影与输出投影一共有 $4d^2$ 个参数，这一数量与头数无关：当总宽度固定时，头数越多，每个头就越窄。因此，multi-head attention 的参数量和计算量与相同宽度的单头注意力大致相当。

在工程实现中，通常会把所有头的投影合并为一个 $d\times d$ 的矩阵，先通过一次矩阵乘法得到 [B,L,d]，再将其重排为 [B,H,L,d/H]，这相当于先将最后一个特征轴拆为 [H,d/H]，再交换 head 与位置轴，使每个 head 的 $L\times L$ 权重独立归一化。各头计算完成后，逆变换把 [B,H,L,d/H] 还原为 [B,L,d]，再执行输出投影。这种重排与逐头投影在数学上等价，也不会使各头共用注意力权重。

那么，多个头之间能否合并为一个头呢？多头结构的作用正在于每个头都拥有独立的注意力分布。不妨假设两个头共用同一个 $A$：

此时，值投影与输出投影就可以合并为一个矩阵，multi-head attention 也就退化为了单头注意力。只有当各个头产生不同的 $A_1,A_2$ 时，才无法从中提取出公共的 $A$，不同的关注方式也才能共同作用于输出。

需要说明的是，头的编号仅用于区分参数组，并没有预设的分工。对训练后模型的分析发现，一些头会呈现出可以辨认的模式，例如关注前一个位置，或者关注句法上的依存词；但也有研究（Michel 等，2019）发现，许多头在推理时可以被剪除，而几乎不影响模型效果，这说明头与头之间存在相当程度的冗余。

此外，多头结构同样适用于 cross-attention（交叉注意力）：此时，Q 来自查询序列，K/V 来自被查询的序列，每个头的权重形状为 $n_q\times n_k$，而输出保留 $n_q$ 行。

3. self-attention 的置换等变性

3.1 证明

对于上述不含位置信息的注意力，设 $P$ 为一个置换矩阵，它会重新排列输入的行，即 $X'=PX$。那么，$Q'=PQ$、$K'=PK$、$V'=PV$，对应的分数矩阵为：

由于逐行 softmax 与同步的行列重排是可交换的，因此有：

其中，最后一步用到了 $P^\top P=I$。这一结果表明：如果输入按照某种方式重新排列，那么输出也会按照同样的方式重新排列，这一性质被称为置换等变性 (permutation equivariance)。换言之，每个输出向量本身与原来完全相同，只是换了一个位置。

以三位置序列为例，交换第一个和第三个位置之后，中间位置的输出保持不变，而另外两个位置的输出则相互交换。也就是说，模型所看到的只是“同样的几个向量换了位置”，而无法得知“谁在前、谁在后”。因此，仅靠这种运算无法建立 token 的先后关系。例如，若对输出进一步使用不依赖顺序的 pooling，“狗咬人”与“人咬狗”会产生相同的聚合结果。逐位置输出仍会随各 token 移动，不能将 permutation equivariance 与输出矩阵完全不变混为一谈。

3.2 适用范围

此外，逐位置的 FFN（逐位置前馈网络）、LayerNorm（逐位置的特征归一化） 以及对应位置的残差相加，同样保持这一性质。因此，仅仅依靠堆叠这些组件，整个编码器仍然对顺序不敏感。需要说明的是，上述等式以关闭 dropout 为前提；并且，如果使用了掩码，那么掩码也必须随输入同步重排。而固定的下三角 causal mask（因果掩码） 本身就已经引入了先后顺序，因此并不满足置换条件。正因如此，纯解码器模型即使不加 positional encoding，也能从因果结构中获得一定的位置信息。

对于图像而言，情况也是如此。视觉 Transformer 会把图像切分为 patch 序列，在不包含位置线索或空间掩码时，打乱 patch 的顺序只会相应重排输出表示，而对这些表示做不依赖顺序的分类汇聚无法恢复原有的空间布局。

4. 正余弦 positional encoding

4.1 定义

为了打破置换等变性，原始 Transformer 为每个位置 $p$（从 0 开始计数）构造了一个与 token Embedding（将 token 编号映射为可学习向量的表示） 同维的确定性向量，并将其与 token Embedding 相加之后送入网络。对于偶数维度 $d$，第 $r$ 对坐标使用的频率为 $\omega_r=10000^{-2r/d}$：

其中，相邻的两个坐标共用同一个频率。随着维度的增加，频率从 1 按几何级数递减到约 $1/10000$：低维坐标随位置快速振荡，而高维坐标则变化缓慢。这一规律与二进制计数中“低位变化快、高位变化慢”的特点十分相似。此外，原模型会先把 token Embedding 乘以 $\sqrt d$，再与 positional encoding 相加，最后进行 dropout。

5. 其他 positional encoding 方案

5.1 可学习的绝对位置

除了正余弦编码之外，研究者还提出了多种 positional encoding 方案。其中，BERT、GPT-2 与 ViT 采用的是learned positional Embedding（可学习的位置向量）：为每个位置分配一个可训练的向量，其用法与 token Embedding 相同。正余弦编码可以按公式计算任意位置，但模型能否泛化到更长序列仍取决于训练与任务。可学习的位置表通常受限于预设的最大长度。

5.2 相对位置

另一类方案直接建模相对位置。例如，Shaw 等人（2018）提出把相对距离 $j-i$ 的嵌入直接加入注意力分数的计算中；T5 则为不同的相对距离区间学习一个标量偏置。在此基础上，ALiBi（Press 等，2021）更进一步，它不引入任何参数，而是直接给分数加上一个与距离成正比的负偏置，从而使远处位置的权重自然衰减。

5.3 RoPE

在各种方案中，RoPE（Rotary Position Embedding，旋转位置编码）在 LLaMA 等语言模型中广泛使用。与前述方法不同，它并不修改输入，而是在 Q/K 投影之后，把每对坐标按照位置旋转一个角度。以二维情形为例，位置 $p$ 决定一个旋转角度。

在高维情形下，RoPE 把向量两两分组，每一组都按照各自的频率旋转。下图以 8 维向量为例：

由此可见，查询与键的绝对旋转量在点积中只以差值 $r-p$ 的形式出现，因此注意力分数只依赖于内容与相对位置。具体而言，在 Q/K 内容固定的情况下，把两者的位置同时平移相同的量，点积保持不变；如果可访问的位置集合也保持不变，那么整行的权重都不会改变。标准 RoPE 在 Q/K 上实施这一变换，V 保持不变。相对位移结构并不自动保证超出训练长度时仍能准确预测；新的位置范围会改变模型见到的旋转相位组合。

下面的交互图使用了三位置序列的固定投影，每个头只有一对二维旋转坐标，频率取 1，默认的 Query 为位置 2。可以观察到，增大共同的位置偏移时，Q 与 K 会以相同的角度旋转，因此二者的相对角度与点积保持不变；而 Key 选择器则用于改变参与比较的位置及其相对距离。

至此，注意力子层的计算已经完整：multi-head attention 负责位置之间的信息交互，positional encoding 提供次序信息，而输出投影则把结果映射回模型维度。下一章将讨论如何把这个子层与前馈网络组织成可以深层堆叠的结构。

09 残差网络、LayerNorm 与 FFN
前两章讨论的注意力机制解决了“位置之间如何交换信息”的问题。然而，Transformer 需要把注意力与特征变换组合为多层网络；原始模型使用六层编码器和六层解码器，后续模型还会增加堆叠深度。增加层数扩大了可组合的特征变换，但也延长了信号与梯度的传播路径。各层 Jacobian（雅可比矩阵）的连乘可能压缩或放大梯度，激活值的尺度也可能随层数变化，使深层网络难以优化。 原始 Transformer 用三类组件组织上述计算：残差连接 (Residual Connection) 为信号和梯度提供跨层的直接通路；LayerNorm（逐位置的特征归一化） 对每个位置的特征向量进行归一化；FFN（逐位置前馈网络） 则为每个位置提供非线性特征变换。这三个组件与注意力子层共同构成可堆叠的编码器层。 1. 深层网络的退化与残差连接1.1 退化问题直觉上，更深的网络至少不应该比浅的网络更差：因为多出来的层只要学成恒等映射，深层网络就能够复现浅层网络的结果。然而，He 等人在 2015 年的实验中观察到了相反的现象：在 CIFAR-10 数据集上，56 层的普通卷积网络，其训练误差反而高于 20...
