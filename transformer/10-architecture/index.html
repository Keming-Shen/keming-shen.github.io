10 Transformer 网络结构

发表于2026-09-29|更新于2026-10-07|「CV」看得见的计算机视觉从神经网络到 Transformer
|浏览量:

前面各章分别建立了跨位置的信息聚合、顺序表示和深层特征变换。要完成机器翻译，还需要将这些组件组织成一条条件生成的数据流：源句各位置的表示必须能够被不同目标位置读取，而目标预测只能依赖已有前缀。

原始 Transformer 为此采用 Encoder–Decoder 结构：首先，编码器形成完整源序列的上下文表示；随后，解码器交替处理目标前缀和读取源端信息，最后输出目标词表上的分布。Embedding（将 token 编号映射为可学习向量的表示）、positional encoding（位置编码）、multi-head attention（多头注意力）、LayerNorm（逐位置的特征归一化） 与 FFN（逐位置前馈网络） 在这条数据流中具有不同的作用，目标右移和 causal mask（因果掩码） 则共同保证训练时不泄露答案。

1. 整体结构与模型配置

1.1 结构概览

从整体上看，原始 Transformer 由编码器堆栈和解码器堆栈两部分组成。其中，编码器读取完整的源序列，并输出每个源位置的上下文表示；而解码器则以右移之后的目标序列作为输入，在每一层中通过 cross-attention（交叉注意力） 读取编码器的输出，最终预测下一个目标 token。

2. 输入表示

首先来看数据流的起点。源序列的 token 编号经过 Embedding table 映射为向量，乘以 $\sqrt{d_{\mathrm{model}}}$ 之后与正余弦 positional encoding 相加，最后再进行 dropout：

这样一来，长度为 $S$ 的源序列就被表示为一个 $S\times512$ 的矩阵，其中每一行都同时包含了 token 的内容信息与位置信息。同样地，解码器也会对右移之后的目标输入执行相同形式的计算。

嵌入缩放的一种解释与数值尺度有关：嵌入参数通常以较小的方差进行初始化（并且与输出层共享），而 positional encoding 的每个分量都在 $[-1,1]$ 之间，因此放大嵌入可以避免位置信号在相加之后压过内容信号。

3. 编码器

在输入表示之上，编码器的每一层都包含两个子层：multi-head self-attention（多头自注意力） 与 FFN，并且二者均采用 Post-LN 结构（第 09 章）。设第 $\ell$ 层的输入为 $X^{(\ell-1)}$，则有：

需要注意的是，编码器的 self-attention 并不使用 causal mask。这是因为用于翻译的源句在生成开始之前就已经完整可用，所以每个源位置都可以读取其他所有位置，只需要屏蔽批量补齐所产生的 <pad> 即可。在此基础上，每一层都会在已经包含上下文的表示之上继续进行匹配与汇聚，再由 FFN 进行逐位置的变换。第一层已经可以访问完整源句；继续堆叠扩大的是上下文变换的深度，而不是第一次获得更远位置的访问权限。模型能否学到有效的高层关系，仍由参数与训练目标决定。

4.2 cross-attention

接下来是第二个子层。cross-attention 以解码器的当前表示作为查询，并以编码器的输出作为键和值的来源：

具体而言，当目标长度为 $T$、源长度为 $S$ 时，分数矩阵的形状为 $T\times S$，而输出保留 $T$ 行。在这一过程中，每个目标位置的查询已经通过前一个子层汇聚了目标前缀的信息，因此可以据此从源端读取所需的内容。另外，cross-attention 不使用三角掩码，只需要屏蔽源端的填充位置即可。

最后，在经过 $N$ 层解码器之后，目标前缀的表示与源端的信息会反复交互，最终形成用于词表预测的表示。

5.2 label smoothing

原始 Transformer 使用强度 $\epsilon_{ls}=0.1$ 的 label smoothing（对目标分布分配少量非目标概率质量）。它保留目标 token 的主要概率质量，同时向其他候选分配少量质量。下式采用 PyTorch 的约定，将 one-hot（以单个非零分量表示类别身份） 目标与全部类别上的均匀分布混合：

在前面的模型定义中，forward() 构造了三种掩码，其用途如下图所示：

在这段实现中，有以下几个要点值得注意：

  • 逐层实例化。 使用 ModuleList 逐个创建各层，可以保证各层的参数相互独立。反之，如果把同一个层对象重复放入列表，各层就会共享参数。
  • 三种掩码。 编码器 self-attention 使用 src_key_padding_mask；解码器 self-attention 同时使用 tgt_mask（causal mask）与 tgt_key_padding_mask；而 cross-attention 使用的是 memory_key_padding_mask，这是因为它的键和值来自源端。需要注意的是，这些接口的布尔掩码中，True 表示禁止访问。
  • 输入与标签对齐。 target[:, :-1] 作为解码器的输入，target[:, 1:] 作为标签，二者恰好错开一位。此外，模型的输出形状为 [B,T,|V|]，将前两维展平之后，每一行 logits 都与展平后的一个标签相对应。
  • 损失接口。 CrossEntropyLoss 接收原始的 logits，并能够同时处理填充标签与 label smoothing。

模型的梯度由词表损失出发，经解码器各子层、cross-attention 和编码器反向传递。共享 Embedding 矩阵同时接收源端查表、目标端查表和输出词表投影的梯度；优化器将这些梯度共同用于一次参数更新。完整训练流程见第 11 章。

7.1 Adam 与 warmup 调度

原始 Transformer 使用的优化器是 Adam，其参数为 $\beta_1=0.9$、$\beta_2=0.98$、$\epsilon=10^{-9}$，并且学习率按照步数 $t$ 进行调整：

具体而言，在前 4000 步中，学习率线性增长（即warmup（训练初期逐渐提高学习率））；此后，学习率按照步数平方根的倒数进行衰减，因此峰值出现在第 4000 步。结合第 09 章的讨论，由于 Post-LN 在训练初期的梯度分布不均、对学习率较为敏感，warmup 的目的正是为了避免初期的大步更新破坏训练。相比之下，采用 Pre-LN 的模型通常可以缩短甚至去掉 warmup 阶段。

7.2 训练与解码

训练流程从句对预处理开始：源端与目标端数据先转换为各自的 token 序列，再按相近长度组成句对批次。英德实验使用约 450 万句对和共享 BPE 词表；英法实验使用约 3600 万句对和约 32000 项的 WordPiece 词表。源端 Padding、目标右移、目标 Padding 和逐位置损失分别在批次构造、注意力与训练目标中处理。

Base 模型在 8 块 NVIDIA P100 GPU 上训练了 10 万步，耗时约 12 小时；Big 模型训练了 30 万步，耗时约 3.5 天。其中，每个批次包含约 25000 个源 token 与 25000 个目标 token，并且句子按照长度相近的原则进行分批。

在训练阶段，teacher forcing（训练时使用参考序列的正确前缀） 与 causal mask 使所有目标位置能够在一次前向计算中并行处理。而在推理阶段，模型则从 <bos> 开始逐步生成：编码器的输出在整个生成过程中被复用，每一步都取最后一个位置上的词表分布。原始 Transformer 的解码设置为束宽 4、长度惩罚系数 0.6，最大输出长度为输入长度加 50。

08 多头注意力与位置编码
上一章介绍的单头注意力存在两个局限。第一，一个 head 为每个 Query 只产生一组权重，所有 Value 特征都按这组权重聚合。若不同特征需要读取不同位置，单一加权分布就需要在这些关系之间折中。例如，一个动词的表示可能需要同时整合主语、宾语和时间状语。第二，注意力的计算只依赖于向量的内容，而与位置无关；在不包含位置信息和顺序掩码时，重排输入只会同样重排输出，不能为相同内容赋予不同的顺序语义（第 3 节）。 针对这两个问题，Transformer 分别引入了 multi-head attention（多头注意力） 与 positional encoding（位置编码）。其中，multi-head attention 的思路与卷积网络相通：卷积层使用多个卷积核，并行地提取边缘、纹理等不同特征，再在通道维度上合并；类似地，multi-head attention 使用多组投影，并行地计算不同的注意力分布，再在特征维度上合并。而 positional encoding 则是把位置信息显式地注入输入或注意力分数之中。 1. multi-head attention1.1...
